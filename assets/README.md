# รูป Rich Menu

`rich-menu.png` — 2500 × 1686 px, 8 ปุ่ม (4 คอลัมน์ × 2 แถว) โทนม่วงม่วงจด
ขนาดไฟล์ ~244 KB (LINE จำกัด 1 MB)

## โครงของรูป (ต้องตรงกับ `scripts/create-rich-menu.js`)

| ส่วน | พิกัด y | กดได้ไหม |
|---|---|---|
| แถบหัว (น้องหมาโผล่ + ข้อความ) | 0 – 150 | ไม่ |
| การ์ด 8 ปุ่ม (ช่องละ 625 × 693) | 150 – 1536 | ✅ |
| แถบท้าย (โลโก้ ม่วงจด) | 1536 – 1686 | ไม่ |

## ปุ่มทั้ง 8 (เรียงซ้าย→ขวา บน→ล่าง)

| # | ปุ่ม | ข้อความที่ต้องส่ง |
|---|---|---|
| 1 | บันทึกงานวันนี้ | `บันทึกงานวันนี้` |
| 2 | แนบสลิป/หลักฐาน | `แนบสลิป/หลักฐาน` |
| 3 | รายการล่าสุด | `รายการล่าสุด` |
| 4 | สรุปวันนี้ | `สรุปวันนี้` |
| 5 | แก้ไขล่าสุด | `แก้ไขล่าสุด` |
| 6 | ยกเลิกล่าสุด | `ยกเลิกล่าสุด` |
| 7 | ค้างรับ | `ค้างรับ` |
| 8 | ช่วยเหลือ | `ช่วยเหลือ` |

ทุกข้อความอยู่ใน `src/utils/menuCommands.js` แล้ว — ตั้งปุ่มเป็นแบบ "ส่งข้อความ"
ใน LINE OA Manager ก็ใช้ได้ทันที หรือใช้ `npm run rich-menu` เพื่อสร้างเป็น
postback ผ่าน API

## วาดรูปใหม่

```bash
npm i --no-save playwright @fontsource/noto-sans-thai sharp
node scripts/build-rich-menu.mjs
```

สคริปต์อ่านรูปน้องหมาจาก `public/brand/` วาดด้วย headless Chromium แล้วเขียนทับ
`assets/rich-menu.png` — แก้ข้อความ/ไอคอน/สีได้ในไฟล์สคริปต์
