ในสองสคริปต์ต้องตรงกัน — ตั้งปุ่มเป็นแบบ "ส่งข้อความ" ใน LINE OA Manager
ก็ใช้ได้ทันที หรือใช้ `npm run rich-menu` เพื่อสร้างเป็น postback ผ่าน API

## วาดรูปใหม่

```bash
npm i --no-save playwright @fontsource/noto-sans-thai sharp
node scripts/build-rich-menu.mjs
```

สคริปต์อ่านโลโก้และรูปน้องหมาจาก `public/brand/` วาดด้วย headless Chromium
แล้วเขียนทับ `assets/rich-menu.png` — แก้ข้อความ/ไอคอน/สีได้ในไฟล์สคริปต์

เปลี่ยนจำนวนแถว/คอลัมน์เมื่อไหร่ ต้องแก้ `LAYOUT` ใน `create-rich-menu.js`
ให้ตรงกันด้วย (เทสต์จะฟ้องถ้าลืม)
