# stationery-bot

บอท LINE OA ช่วยตอบลูกค้าร้านเครื่องเขียน (แยกจากบอท "ม่วงจดให้" ที่อยู่โฟลเดอร์ด้านนอก ไม่ใช้โค้ดร่วมกัน)

ตอบจากข้อมูลที่ร้านกรอกเองใน `data/shop.json` — ไม่ใช้ AI:

- **สินค้า** พิมพ์ชื่อ/ชื่อเรียก → บอกราคา ราคายกจำนวนมาก และมี/หมดสต็อก
- **คำถามทั่วไป (FAQ)** เวลาเปิด ที่ตั้ง จัดส่ง ชำระเงิน โปร ใบเสร็จ — จับจากคำสำคัญ
- **ตอบทันที** (ตั้งรอได้ที่ `replyDelaySeconds` 0 = ทันที)
- **ติดต่อแอดมิน** ลูกค้ากดปุ่มดำ "ติดต่อแอดมิน" → การ์ด "ติดต่อ หญิง / ฟิล์ม / พี่ปิ่น" (มีรูปโปรไฟล์ไลน์ของแต่ละคน) (`contact` ใน `data/shop.json`)
  - ลูกค้ากดชื่อ → บอท**เงียบ**กับลูกค้าคนนั้น (20 นาทีที่ไม่มีข้อความ แล้วกลับมา หรือลูกค้าพิมพ์ "เมนู") และมี**การ์ดแจ้งเตือนเด้งเข้าไลน์ของคนที่ถูกเลือก**
  - ข้อความที่บอทไม่เข้าใจ และรูป/สลิป → บอท**ไม่ตอบลูกค้า** แต่ส่งการ์ดแจ้งเตือนหาแอดมิน**ทั้ง 3 คน** (ไม่เกิน 1 ครั้งต่อลูกค้าต่อ 10 นาที: `notifyAllMinutes`)
  - ใส่ `userId` ของแต่ละคนใน `contact.people` (ให้แต่ละคนเพิ่มเพื่อน OA แล้วพิมพ์ "ไอดีฉัน")
  - ข้อความแจ้งเตือนเป็น push ของ OA นับโควตาข้อความรายเดือน (ปิดได้ด้วย `"notify": false` ถ้าใช้แจ้งเตือนของแอป OA แทน)
- ปิดบอทชั่วคราว: `"paused": true` หรือแอดมินพิมพ์ "ปิดบอท" (ดู `ADMIN_USER_IDS`) ระหว่างรอ 90 วินาที จะยกเลิกคำตอบที่ค้างอยู่
- หัวข้อที่ยังไม่มีข้อมูลจริง ปิดไว้ด้วย `"enabled": false` (FAQ) / `"productsEnabled": false` (สินค้า)
- แก้ `data/shop.json` ได้เลยโดยไม่ต้อง restart

## รัน
```bash
cp .env.example .env   # ใส่ LINE_CHANNEL_ACCESS_TOKEN / LINE_CHANNEL_SECRET
npm install
node --env-file=.env src/server.js
npm test
```
ตั้ง Webhook URL ใน LINE Developers เป็น `https://<โดเมน>/webhook` (ปิด "Auto-reply messages" ใน OA Manager)

## แก้ข้อมูลร้าน (`data/shop.json`)
- `products[]`: `name`, `aliases` (คำที่ลูกค้าใช้เรียก), `price`, `unit`, `bulk` (ไม่บังคับ), `inStock`
- `faq[]`: `keywords` (ลูกค้าพิมพ์คำใดคำหนึ่งก็ตรง), `label`, `answer`
- `greeting`, `fallback`, `handoff`, `quickReplies`
ข้อมูลในไฟล์เป็นตัวอย่าง ต้องแก้เป็นของร้านจริงก่อนใช้งาน

## อ่านสลิป

ลูกค้าส่งรูปสลิปมา บอทดูแค่ว่าเป็นสลิปหรือไม่ (ไม่อ่านยอดเงิน) แล้วตอบ "ขอบคุณค่ะ" — แอดมินตรวจยอดเอง
ไม่ตั้ง key = โหมดฟรี: ทุกรูปได้ "ขอบคุณค่ะ ได้รับรูปแล้ว" และแอดมินได้รับแจ้ง ถ้าอยากให้บอทแยกสลิปออกจากรูปอื่น ตั้ง `GEMINI_API_KEY` (แผนฟรีของ Google AI Studio) หรือ `ANTHROPIC_API_KEY` (คิดเงิน)
รูปที่ไม่ใช่สลิป / อ่านไม่ออก / ไฟล์อื่น → บอทไม่ตอบ แจ้งแอดมินทั้ง 3 คน

## ข้อความที่บอทไม่เข้าใจ

บอทตอบสั้น ๆ ว่า "รับเรื่องแล้วค่ะ แอดมินจะตอบกลับในแชทนี้นะคะ" (ตั้งที่ `contact.receivedNote` — เว้นว่างถ้าอยากให้เงียบ) พร้อมปุ่มหัวข้อด้านล่าง และแจ้งแอดมินทั้ง 3 คน

โหมดไม่เสียเงิน: `contact.notify:false` (ไม่ push หาแอดมิน ใช้แจ้งเตือนของแอป OA) และ `contact.askOnUnknown:true` (ข้อความที่ไม่เข้าใจ → ตอบการ์ดถามว่าจะคุยกับใคร; ทักครั้งแรกก็ถามเช่นกัน; กดชื่อแอดมินแล้วบอทเงียบ)

**แจ้งเตือนแอดมิน (push)** ส่งเฉพาะ: ลูกค้าสั่งงาน/สั่งของ (คำใน `contact.orderWords`), ส่งสลิป/รูป, และเมื่อลูกค้ากดชื่อแอดมิน ข้อความที่บอทไม่เข้าใจ: เงียบ ไม่แจ้ง (`contact.askOnUnknown:false`)

## ถามว่าจะคุยกับใคร (ต่อการทักแต่ละครั้ง)

ลูกค้าคนหนึ่งนับเป็น "การทักหนึ่งครั้ง" (visit) เมื่อส่งข้อความครั้งแรกของวัน (เวลาไทย) หรือหายไปเกิน `contact.sessionGapHours` ชั่วโมง (ตอนนี้ 4) แล้วทักมาอีก
- **ทักสวัสดีล้วน ๆ** (เช่น "สวัสดีค่ะ", "hello") เป็นข้อความแรกของ visit → บอทส่งการ์ด "ต้องการติดต่อใครคะ" ให้เลือกแอดมินเลย (แทนการ์ดเมนู) พร้อมปุ่มหัวข้อด้านล่าง ส่งไม่เกินหนึ่งครั้งต่อ visit
- สวัสดีครั้งต่อไปใน visit เดิม → การ์ดเมนูตามปกติ; พิมพ์ "เมนู" ได้เมนูเสมอ
- **ข้อความที่บอทไม่เข้าใจ → เงียบเสมอ แม้เป็นข้อความแรกของวัน** (มักเป็นการตอบแอดมินที่กำลังคุยกับลูกค้าอยู่ — LINE ไม่บอกบอทว่าแอดมินตอบไปแล้ว)
- ถามเรื่องที่บอทตอบได้ (เช่น เวลาเปิดร้าน) → ตอบตามปกติ
- ลูกค้ากดเลือกชื่อแล้ว → ไม่ถามซ้ำใน visit นั้น
- ปิดได้ด้วย `contact.sessionAsk: false` (บอทรีสตาร์ทแล้วจะถามลูกค้าที่กลับมาอีกครั้งหนึ่งครั้ง เพราะจำไว้ในหน่วยความจำ)

## ข้อความที่ส่งติดกัน

LINE อาจส่งข้อความหลายบรรทัดของลูกค้ามาใน webhook ครั้งเดียว บอทจึงประมวลผลทีละข้อความต่อลูกค้าหนึ่งคนตามลำดับ (`src/serial.js`) แล้วตอบแค่ครั้งเดียว ข้อความที่ตามมาภายใน `contact.burstSeconds` (6) วินาทีหลังบอทตอบจะถูกข้าม

## แจ้งเตือนแอดมิน ไม่เกิน 1 ครั้งต่อลูกค้าต่อ 5 ชั่วโมง

การ์ดแจ้งเตือนแอดมิน (push นับโควตา OA) ส่งไม่เกิน 1 ครั้งต่อลูกค้าหนึ่งคนต่อ `contact.alertEveryHours` ชั่วโมง (ตอนนี้ 5) ไม่ว่าลูกค้าจะส่งรูป/สลิปมากี่ครั้ง และลูกค้ากดชื่อแอดมินคนเดิมซ้ำก็ไม่แจ้งซ้ำ (กดแอดมินคนอื่นแจ้งคนนั้น)
การตอบ "ขอบคุณค่ะ ได้รับรูปแล้ว" ฟรี (ไม่นับโควตา) จึงยังตอบได้ แต่รูปที่ส่งติดกันได้คำตอบเดียวต่อ `contact.pictureReplyMinutes` นาที (ตอนนี้ 10)

## เมนูถาวรใต้แชท (ริชเมนู)

เมนู 3 ปุ่มใหญ่ (รูป `assets/richmenu.png` ขนาด 2500×843) ขึ้นใต้ช่องพิมพ์ของลูกค้าทุกคน เปิดค้างไว้เป็นค่าเริ่มต้นทุกครั้งที่เปิดแชท (`richMenu.selected: true`)
- **ติดตั้ง:** แอดมินพิมพ์ **"ติดตั้งเมนู"** ในแชทกับ OA (ต้องเป็นบัญชีแอดมินของร้าน) — บอทอัปโหลดรูปและตั้งเป็นเมนูของทุกคนเอง แล้วบอกผลกลับ
- **เอาออก:** พิมพ์ **"ลบเมนู"** (ลบเฉพาะเมนูที่บอทนี้สร้าง ชื่อ `richMenu.name` — ไม่แตะเมนูอื่นของ OA)
- ปุ่มแต่ละช่องตั้งที่ `richMenu.areas` (ข้อความที่ปุ่มส่งเป็นข้อความของลูกค้า บอทตอบเหมือนลูกค้าพิมพ์เอง): สั่งซื้อสินค้า → "สั่งของ", ส่งเอกสารโครงการ → การ์ดให้ส่งไฟล์และเลือกแอดมิน (`contact.documentAsk`), คุยกับแอดมิน → "ติดต่อแอดมิน"
- เปลี่ยนรูป: แทนที่ `assets/richmenu.png` (ต้อง PNG/JPEG ขนาด 2500×843 ไม่เกิน 1 MB) แล้วพิมพ์ "ติดตั้งเมนู" ใหม่ (เมนูเก่าชื่อเดียวกันจะถูกแทนที่)
- ข้อจำกัดของ LINE: ริชเมนูกับแป้นพิมพ์ใช้พื้นที่เดียวกัน กดช่องพิมพ์แล้วเมนูจะหุบ กดไอคอนเมนูมุมซ้ายล่างเพื่อเปิดกลับ; แสดงเฉพาะในแอปมือถือ
- การแตะปุ่มเมนู/ปุ่มหัวข้อคนละปุ่มติดกันไม่ถูกตัดตามกติกา "ตอบครั้งเดียว" และปลุกบอทได้แม้อยู่ในช่วงเงียบหลังเลือกแอดมิน
- ลูกค้าส่งไฟล์ (PDF ฯลฯ) → บอทตอบ "ได้รับไฟล์แล้ว" และแจ้งแอดมิน (ไม่เกิน 1 ครั้งต่อลูกค้าต่อ 5 ชั่วโมง) บอทไม่อ่านไฟล์
