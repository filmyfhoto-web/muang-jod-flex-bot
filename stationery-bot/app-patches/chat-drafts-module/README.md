# โมดูล "ออเดอร์จากแชท" (chatorders) สำหรับหน้าหลังร้าน

หน้าหลังร้านเก็บโค้ดของแต่ละหน้าไว้ในตาราง `app_modules` · โมดูลนี้เป็น **แถวใหม่** (`chatorders`, seq 65, ปิดไว้เมื่อติดตั้ง) ไม่แก้โมดูลเดิม

| ไฟล์ | ทำอะไร |
|---|---|
| `chatorders.module.js` | ตัวโมดูล (แก้ที่นี่ที่เดียว) |
| `make-sql.mjs` | สร้าง `apply.sql` / `reverse.sql` จากไฟล์โมดูล (`node app-patches/chat-drafts-module/make-sql.mjs`) |
| `apply.sql` | ติดตั้ง: เพิ่มแถวปิดไว้ (ทำซ้ำได้) |
| `reverse.sql` | ถอด: ลบแถว ถ้าโค้ดยังเป็นรุ่นที่ติดตั้ง (ตรวจด้วย md5) |

ขั้นตอนติดตั้งและเปิดใช้: ดู `docs/chat-to-order/03-enable-guide.md` (ต้องติดตั้ง `db/migrations/001_chat_drafts.sql` ก่อน เพราะหน้านี้เรียกฟังก์ชัน `chat_draft_*`)

## ทำอะไรบ้าง
- รายการร่างแยกแท็บ: รอตรวจ · พร้อมยืนยัน · ยืนยันแล้ว · ยกเลิก (นับจำนวนในแท็บ)
- ร่าง: ข้อมูลลูกค้า รายการสินค้า (แก้จำนวน หน่วย ราคา รับรองรายการ ลบ เพิ่ม ผูกสินค้า) ข้อความจากแชทและรูป (ลิงก์ชั่วคราว) ประวัติการเปลี่ยนแปลง
- ปุ่ม: บันทึก · ยืนยันเป็นออเดอร์ · ยกเลิกร่าง · พิมพ์ใบจัดของ · เปิดคำสั่งซื้อ · ขายผ่าน POS
- วางข้อความจากแชทเพื่อสร้างร่างเอง (`chat_draft_manual`)
- ลิงก์จากการ์ด LINE `?chat=CH-0001#chatorders` เปิดร่างนั้นทันที

## สิ่งที่โมดูลนี้ **ไม่** ทำ
- ไม่เขียนตารางโดยตรง (ทุกการเขียนผ่านฟังก์ชัน `chat_draft_*` ที่มีประวัติ)
- ไม่ตัดสต็อก (สต็อกถูกตัดเฉพาะตอนขาย POS หรือเอกสารเดิม)
- ไม่ส่งข้อความถึงลูกค้า

## เมื่อแก้โค้ดโมดูล
1. แก้ `chatorders.module.js` · รัน `node app-patches/chat-drafts-module/make-sql.mjs`
2. รันทดสอบ: `cd db && npm test` (รวม `module-sql.test.js` ที่ตรวจว่า `apply.sql`/`reverse.sql` ตรงกับโค้ด)
3. ทดสอบหน้าจอในเบราว์เซอร์: `NATTA_LIVE_DIR=<โฟลเดอร์สำเนาหน้าหลังร้าน> npm run test:ui` (ดู `docs/chat-to-order/02-design-and-test.md` ข้อ 4.3)
4. ถ้าติดตั้งแล้วบนระบบจริง: ต้องให้เจ้าของรัน `reverse.sql` (ของรุ่นเก่า) แล้วรัน `apply.sql` (ของรุ่นใหม่) ตามลำดับ · ตรวจว่าแถวเดิมถูกแทนที่ก่อนเปิด

## เกี่ยวกับกติกาการอ่านข้อความ
ฟังก์ชันจัดการข้อความในโมดูล (`parsePasted`, หน่วยจาก `UNIT_ALIAS`, คำที่ขอสินค้า) คัดลอกมาจาก `src/picklist.js` และ `src/orders/draft.js` ของบอท ถ้าแก้กติกาฝั่งบอท ต้องแก้ที่นี่ด้วย (ระบุไว้ในไฟล์โมดูลแล้ว)
