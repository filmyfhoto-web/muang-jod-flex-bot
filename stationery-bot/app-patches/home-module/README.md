# โมดูล "ภาพรวม" (overview) สำหรับมือถือ

หน้า **ภาพรวม** ในเมนูหลังร้าน: มือถือเป็นแถบล่างช่องที่ 2 · คอมพิวเตอร์เป็นเมนูซ้ายลำดับที่ 2 (ต่อจาก "หน้าหลัก")

| ในหน้า | ดูจาก |
|---|---|
| ยอดออเดอร์เดือนนี้ และจำนวนวันนี้ | `orders` (ไม่รวมที่ยกเลิก) |
| ออเดอร์รอดำเนินการ · ใบจัดของยังไม่เก็บ · สินค้าใกล้หมด · ขายหน้าร้านเดือนนี้ | `orders` · `pick_slips` · `products` (จุดสั่งซื้อ) · `sales` |
| รอตรวจจากแชท | `chat_drafts` (แสดงเมื่อติดตั้ง migration 001 แล้วเท่านั้น) |
| สินค้าใกล้หมด (5 รายการ) · ออเดอร์ล่าสุด (5 รายการ) | ตารางเดียวกัน กดแล้วเปิดหน้าที่เกี่ยวข้อง |

**ไม่ทำอะไร:** ไม่เขียนข้อมูล ไม่ตัดสต็อก ไม่แทนที่ "หน้าหลัก" เดิม และไม่ตั้งเป็นหน้าเริ่มต้น (พนักงานยังเข้าหน้าหลักเดิมก่อน)

## ไฟล์

| ไฟล์ | ทำอะไร |
|---|---|
| `../../db/migrations/002_home_summary.sql` | ฟังก์ชัน `home_summary()` อ่านอย่างเดียว (security invoker: ใช้ RLS ของผู้ใช้) |
| `../../db/migrations/002_home_summary.reverse.sql` | ลบฟังก์ชัน (ถอดโมดูลก่อนเสมอ) |
| `overview.module.js` | ตัวโมดูล (แก้ที่นี่ที่เดียว) |
| `make-sql.mjs` | สร้าง `apply.sql` / `reverse.sql` จากตัวโมดูล: `node app-patches/home-module/make-sql.mjs` |
| `apply.sql` | ติดตั้ง: เพิ่มแถวโมดูลแบบปิดไว้ (ทำซ้ำได้) |
| `reverse.sql` | ถอด: ลบแถว เฉพาะเมื่อโค้ดยังตรงกับรุ่นที่ติดตั้ง (md5) |

## ขั้นติดตั้งและเปิดใช้ (ยังไม่ได้ทำ — รอการอนุมัติ)

1. รัน `db/migrations/002_home_summary.sql` ใน SQL Editor ของ Supabase
2. รัน `apply.sql` (โมดูลจะปิดไว้)
3. ตรวจ: `select name, enabled, seq from app_modules where name = 'overview';` → `enabled = false`, `seq = 66`
4. เปิด: `update app_modules set enabled = true where name = 'overview';` แล้วรีเฟรชหน้าหลังร้าน

## ย้อนกลับ

| ต้องการ | ทำ |
|---|---|
| ซ่อนทันที | `update app_modules set enabled = false where name = 'overview';` |
| ถอดโมดูล | รัน `reverse.sql` (ลบเฉพาะถ้ายังไม่มีการแก้โค้ด) |
| ลบฟังก์ชัน | รัน `002_home_summary.reverse.sql` หลังถอดโมดูลแล้วเท่านั้น |
