# หน้าสรุปออเดอร์ (รุ่น 16) — ไฟล์พร้อมติดตั้ง ยังไม่ได้ติดตั้งในระบบจริง

`../saleorders.module.js` คือรุ่น 16 แล้ว และ `../saleorders.module.v15.js` คือรุ่น 15 (แช่แข็งไว้ย้อนกลับได้) ไฟล์ `saleorders.module.v16-preview.js` ตรงกับ `../saleorders.module.js` ทุกไบต์

## สิ่งที่เปลี่ยนจากรุ่น 14

- หน้าตาตามแบบที่เจ้าของส่งมา: คอลัมน์รายชื่อแคบ หน้าแชตกว้าง ข้อมูลลูกค้าเป็นการ์ด รายการอ่านอย่างเดียว ยอดรวมและปุ่มส่งสรุปอยู่ด้านล่างเสมอ
- การ์ดในแชต "ระบบสรุปรายการจากแชทให้แล้ว" แสดงเมื่อใบยังไม่มีรายการ และอ่านรายการจากข้อความลูกค้าได้ กดแล้วเปิดหน้าตรวจเดียวกับ "สร้างรายการจากแชต" ไม่บันทึกเองจนกว่าพนักงานจะกดเพิ่ม
- การส่งสรุปเข้า LINE ต้องกดยืนยันซ้ำทุกครั้ง
- รุ่น 15 (รวมปุ่มจัดการแชตเป็นเมนูเดียว เริ่มที่แท็บ "รอตอบ") รวมอยู่ด้วย

## ขั้นตอนติดตั้ง (ทำใน SQL Editor ของโปรเจกต์ที่ใช้งานจริง)

1. ตรวจว่าตอนนี้เป็นรุ่น 14:
   `select md5(code) as md5, enabled, seq from app_modules where name = 'saleorders';`
   ต้องได้ `5f839f81e02795e4fef24c252f1d03a1`
2. รัน `../upgrade-v14-to-v15.sql` (ข้อความที่ขึ้น: `saleorders: now v15 …`)
3. รัน `../upgrade-v15-to-v16.sql` (ข้อความที่ขึ้น: `saleorders: now v16 …`)
4. ตรวจผล: `select md5(code) as md5, enabled, seq from app_modules where name = 'saleorders';`
   ต้องได้ `74414aaf0715321d5f2dfff8685ff03a`, enabled เป็น `true` และ seq เป็น `66`

ถ้าต้องย้อนกลับ รัน `../downgrade-v16-to-v15.sql` แล้วค่อย `../downgrade-v15-to-v14.sql` แต่ละไฟล์ทำงานเฉพาะเมื่อโค้ดตรงกับรุ่นที่คาดไว้ และไม่ทับโค้ดที่ถูกแก้ไขไว้

ทุกไฟล์ทำงานซ้ำได้ ไม่แก้โมดูลอื่น และไม่แก้ข้อมูลใบสั่งงาน
