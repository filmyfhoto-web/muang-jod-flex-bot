# หน้าสรุปออเดอร์ (ตัวอย่าง รุ่น 16) — ยังไม่ได้ติดตั้งในระบบจริง

`saleorders.module.v16-preview.js` คือหน้า "แชตและออเดอร์" ที่จัดใหม่ตามแบบที่เจ้าของเลือก:

- ส่วนขวาเป็น **สรุปออเดอร์ลูกค้า** มีสถานะที่หัวการ์ด และรายการอ่านอย่างเดียว (ชื่อ จำนวน ราคาต่อหน่วย รวม)
- กด **แก้ไขรายการ** เมื่อต้องการแก้ไข หรือเพิ่มรายการจากแชต/เพิ่มเอง
- ยอดรวมแสดงเป็นการ์ดเดียว และปุ่มหลักคือ **ส่งสรุปให้ลูกค้ายืนยัน** (ยังเปิดตัวสรุปเดิม คัดลอกหรือบันทึกลงแชต ไม่ได้ส่งเข้า LINE)
- ช่องลูกค้า เบอร์ วันที่ ราคา VAT การส่งมอบ สถานะงาน สถานะการชำระ และไฟล์แนบ อยู่ใน **รายละเอียดเพิ่มเติม** (กดเปิดได้)

## สถานะ

- ยังไม่ได้ติดตั้ง ไม่มี SQL ของรุ่นนี้ และ `../saleorders.module.js` ยังเป็นรุ่น 15 เหมือนเดิม
- ก่อนติดตั้ง ต้องติดตั้งรุ่น 14 และ 15 ตามลำดับ แล้วย้ายไฟล์นี้เป็นรุ่น 16 ด้วย `make-sql.mjs` (ให้คนที่มีสิทธิ์รันบนฐานข้อมูลจริง)
