# เปิดใช้ "ลูกค้าพิมพ์สั่งของทางแชท → ใบสั่งจัดในแอปหลังร้าน"

ตอนนี้ **ติดตั้งครบแล้วแต่ปิดสวิตช์ไว้** (บอทบน Render + หน้าเอกสารโครงการในแอปหลังร้าน) — ไม่มีอะไรเปลี่ยนสำหรับลูกค้าและพนักงานจนกว่าจะทำตามนี้

## สิ่งที่ระบบทำเมื่อเปิด

1. ลูกค้าพิมพ์รายการหลายบรรทัดในแชท เช่น `ไม้กวาดทางมะพร้าว=10` / `น้ำยาล้างจาน=1แกลลอน`
2. บอทเงียบ ไม่ตอบลูกค้า สร้าง **ใบใหม่ในแอปหลังร้าน** (หน้า "เอกสารโครงการครู" เลข `PJ-xxxx`, ป้าย "สั่งทางแชท", สถานะ "ใหม่")
   - สินค้าที่ตรงชัดเจนกับสินค้าในร้านจะผูกให้ · ที่เหลือเป็นข้อความของลูกค้าติดป้าย **⚠️ รอตรวจสอบสินค้า** พร้อมบอกสินค้าใกล้เคียง
   - **ไม่ใส่ราคา ไม่ตัดสต็อก ไม่เพิ่ม/แก้สินค้า** — พนักงานเป็นคนตรวจ ใส่ราคา แล้วออกใบสั่งจัดตามขั้นตอนเดิม
3. แอดมินทั้ง 3 คนได้การ์ดใน LINE: "📋 มีรายการสั่งจัดของ … ✅ บันทึกในแอปแล้ว PJ-xxxx" กดปุ่ม "เปิดใบ PJ-xxxx ในแอป" เปิดใบนั้นตรง ๆ (มือถือพนักงานที่ติดตั้งแอปหลังร้านจะเด้งแจ้งเตือนด้วย — หัวข้อมีเลขใบ กดแล้วเปิดหน้ารายการเอกสาร)
4. (ถ้าเปิด) เมื่อพนักงานกดสถานะ **"กำลังทำ"** ในแอป บอทส่งให้ลูกค้าครั้งเดียว: *"ได้รับรายการสั่งซื้อแล้วค่ะ ร้านกำลังดำเนินการจัดสินค้า"* — ไม่ส่งถ้าลูกค้ากำลังคุยกับแอดมินอยู่

## ขั้นตอนเปิดใช้ (ทำตามลำดับ)

### ขั้นที่ 1 — ให้บอทต่อฐานข้อมูลของร้านได้ (ทำครั้งเดียว · **เจ้าของต้องทำเอง** เพราะเป็นรหัสลับ)

Render → บริการ `nattagroup-y` → **Environment** → เพิ่ม 2 ค่า

| ชื่อ | ค่า |
|---|---|
| `SUPABASE_URL` | `https://mamlmgixovlwnjstetkj.supabase.co` |
| `SUPABASE_SERVICE_ROLE_KEY` | Supabase → Project Settings → API → **service_role** (ห้ามส่งในแชท/ห้ามใส่ในโค้ด) |

บันทึกแล้ว Render จะเริ่มใหม่เอง (~2–3 นาที) แล้วเปิด `https://nattagroup-y.onrender.com/health` ต้องได้ `"app":"on"`
(ตอนนี้เป็น `"app":"off"`). การเปิดข้อนี้ทำให้ฟีเจอร์การ์ดของแอปทำงานตามที่ตั้งไว้ในแอป (`line_bot` ตอนนี้ปิดเมนู/เลือกแอดมิน/ส่งเอกสาร) และการ์ดแจ้งเตือนมือถือพนักงานเริ่มส่งได้ — ถ้าไม่พอใจย้อนกลับได้ด้วยการลบ 2 ค่านี้

### ขั้นที่ 2 — ทดลองกับ LINE ของตัวเอง (โหมด `pilot`)

Render → Environment → เพิ่ม `CHATORDERS_MODE` = `pilot` (ไอดี LINE ของฟิล์มตั้งเป็นผู้ทดลองไว้แล้วใน `data/shop.json`; เพิ่มคนอื่นได้ที่ `CHATORDERS_PILOT_IDS` = `Uxxxx,Uyyyy` — ดูไอดีตัวเองโดยพิมพ์ **ไอดีฉัน** ในแชท OA)

ดู `/health` ต้องได้ `"orders":"pilot"` แล้ว:

1. จาก LINE ส่วนตัวของฟิล์ม ส่งข้อความหา OA ร้าน:
   ```
   ไม้ถูพื้น=10
   ไม้กวาดทางมะพร้าว=10
   น้ำยาล้างจาน=1แกลอน
   วันที่ 28
   ```
2. ควรเห็น: บอทเงียบ · แอดมินได้การ์ดมีเลข `PJ-xxxx` · ในแอปหลังร้าน (หน้า "เอกสารโครงการครู") มีใบใหม่ป้าย "สั่งทางแชท"
3. เปิดใบ: เช็กชื่อ/จำนวน/หน่วย · บรรทัดที่ไม่มีในร้านเป็น "⚠️ รอตรวจสอบสินค้า" · ยังไม่มีราคา
4. ส่งข้อความอีก 2 บรรทัดต่อ ภายใน 30 นาที → เข้าใบเดิม (การ์ดบอก "เพิ่มอีก N รายการในใบเดิม")
5. ลบ/ยกเลิกใบทดสอบในแอปเมื่อเสร็จ (สถานะ "ยกเลิก" หรือ "ลบถาวร")
6. (ทดลองแจ้งลูกค้า) เพิ่ม `CHATORDERS_ACK` = `on` แล้วกดสถานะ "กำลังทำ" ที่ใบทดสอบ → ภายใน ~1 นาที LINE ส่วนตัวได้ข้อความ "ได้รับรายการสั่งซื้อแล้วค่ะ …" (ครั้งเดียว) · ในโหมด `pilot` ส่งเฉพาะผู้ทดลอง

### ขั้นที่ 3 — ใช้จริงกับลูกค้าทุกคน

`CHATORDERS_MODE` = `on` (และ `CHATORDERS_ACK` = `on` เมื่อพร้อมให้บอทแจ้งลูกค้า)

## ปิด/ย้อนกลับ (ทำได้ทันที ไม่ต้องรอใคร)

| ต้องการ | ทำอย่างไร |
|---|---|
| หยุดสร้างใบจากแชท | Render → Environment → `CHATORDERS_MODE` = `off` (บอทกลับไปแค่แจ้งแอดมินเหมือนเดิม; ใบที่สร้างแล้วอยู่ในแอป ยกเลิก/ลบได้) |
| หยุดแจ้งลูกค้า | `CHATORDERS_ACK` = `off` |
| หน้าแอปกลับเป็นเหมือนเดิม | รัน `app-patches/projdocs-chat-orders/reverse.sql` ใน Supabase SQL Editor (ได้โมดูลเดิมทุกไบต์) |
| ถอยทั้งบอท | Render → Deploys → เลือกรุ่นก่อน `afa0c8a` → Rollback |

## ควรรู้

- **แชท/ผู้ช่วยอื่นที่แก้โมดูลหลังร้านอยู่**: โมดูล `projdocs` ถูกแก้ไปแล้ว (มีบล็อกหมายเหตุ `(EH 2026-10-26)` ด้านบน) — ถ้าใครเขียนทับทั้งก้อนด้วยสำเนาเก่า แพตช์จะหาย (แอปยังใช้ได้ แค่ใบจากแชทดูเหมือนใบที่ครูส่ง) รัน `apply.sql` ซ้ำได้
- **โควตาข้อความ OA**: การ์ดแจ้งแอดมินส่งหาแอดมิน 3 คน (3 ข้อความ) ต่อรายการ + ข้อความแจ้งลูกค้า 1 ข้อความต่อใบ (ถ้าเปิด) — เฝ้าดูโควตาด้วยคำสั่ง **โควตา** ในแชท OA
- **AI อ่านประโยค** (`CHATORDERS_AI`) ยังปิดอยู่ และต้องมี `GEMINI_API_KEY` หรือ `ANTHROPIC_API_KEY` บน Render — จะส่งข้อความของลูกค้า (เฉพาะข้อความที่ดูเหมือนสั่งของ) ไปยังผู้ให้บริการ AI จึงควรตัดสินใจเรื่องความเป็นส่วนตัวก่อน · ไม่เปิดก็ใช้งานได้ครบ (อ่านได้เฉพาะรายการหลายบรรทัด)
