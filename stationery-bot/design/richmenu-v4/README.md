สร้างจาก 2 ส่วน:

- `top-row.png` — ภาพเมนูเดิม 3 ปุ่ม (2500×843) ใช้เป็นแถวบน **ตัดที่ y = 804** (ใต้การ์ดมีแต่สีพื้นนาวี จึงตัดแล้วไม่เห็นรอยต่อ) แถวบนจึงเหมือนของเดิมทุกพิกเซล

## สร้างภาพใหม่

```bash
cd stationery-bot/design/richmenu-v4
NODE_PATH=$(npm root -g) node render.cjs ../../assets/richmenu.png   # ต้องมี Playwright (Chromium) และฟอนต์ Loma
cp ../../assets/richmenu.png ../../public/richmenu-v4.png
```

แก้ข้อความ/สีในแถวล่างที่ `menu.html` แล้วรันใหม่ · ถ้าเปลี่ยนความสูงของภาพ ต้องแก้ให้ตรงกันที่ `render.cjs` (viewport) · `data/shop.json` (`richMenu.height`, `richMenu.rows`) · `app-patches/line-richmenu/index.ts` (`MENU4`) — เทสต์ `tests/richmenu.test.js` จะล้มถ้าตัวเลขไม่ตรงกัน
