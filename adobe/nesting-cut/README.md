# นัดพอน Nesting Cut ✂️

ปลั๊กอิน **Adobe Illustrator** + **Photoshop** สำหรับร้านสติ๊กเกอร์/ป้าย:
จัดวางชิ้นงาน **ตามรูปทรงจริง** (true-shape nesting) แล้วส่งออกไฟล์ **สั่งเครื่องตัด** ได้ในคลิกเดียว — *เจ๊หญิงสั่งลุย!*

**Nesting · Cut-Line · Marks · Header Logo**

โทนสีกรม + ส้มอิฐ · โลโก้อยู่ที่ `assets/logo.svg` (ตัวอักษรเป็นเส้นแล้ว เปิดแก้ใน Illustrator ได้ ไม่ต้องมีฟอนต์)

| | ทำอะไร |
|---|---|
| ✂️ **Cut-Line** | ชิ้นไหนยังไม่มีเส้นตัด สร้างให้เอง: ตามขอบงาน (อ่านจากความโปร่งใส ใช้ได้ทั้งเวกเตอร์ รูป PNG ตัวหนังสือ) เว้นระยะได้ · ตัดตามเส้นเวกเตอร์ · หรือกรอบสี่เหลี่ยม (มุมมน) — เป็นเส้นสี Spot `CutContour` ที่ RIP ทุกเจ้าอ่านได้ |
| 🧩 **Nesting** | จัดวางตามรูปทรงจริง หมุนได้ 90°/45°/15° เว้นระยะห่างชิ้นตามตั้ง กันสีล้น (bleed) ทับชิ้นข้าง ๆ ลองหลายลำดับแล้วเลือกแบบที่ใช้ม้วนสั้นที่สุด ม้วนยาวเกินขึ้นแผ่นใหม่ให้เอง |
| 🎯 **Marks** | มาร์กสำหรับพิมพ์แล้วตัด: **Graphtec (เลเยอร์ reg_1 แบบ Cutting Master — จำจากไฟล์ต้นแบบของร้านได้)** / จุดวงกลม / สี่เหลี่ยม / L 4 มุม / แบบ Silhouette + มาร์กกลางสำหรับงานยาว — ชิ้นงานหลบมาร์กให้อัตโนมัติ |
| 💰 **ต้นทุน** | ใส่ราคากระดาษ (บาท/แผ่น) → บอกต้นทุนรวมและ **ตกชิ้นละกี่บาท** ทันที (จำราคาแยกตามขนาดกระดาษ) |
| 🏷️ **Header Logo** | หัวงานบนแผ่น: โลโก้ร้าน + ชื่องาน ลูกค้า วันที่ จำนวนชิ้น ขนาดแผ่น |
| 📤 **ส่งออก** | PDF (ให้ RIP พิมพ์+ตัด) · .ai · **PLT** (HP-GL) · **DXF** · **SVG** · รูปพรีวิวส่งลูกค้าทางไลน์ |

```
Photoshop (เลเยอร์ PNG)                      Illustrator
┌─────────────────────────┐   แพ็ก   ┌───────────────────────────────────────────────┐
│ เลือกเลเยอร์ → เส้นตัด  │ ───────▶ │ ดึงชิ้นงาน → เส้นตัด → จัดวาง → เลย์เอาต์ → ส่งออก │ ──▶ RIP / เครื่องตัด
│ ตามขอบ → ส่ง Illustrator│  (json)  │        (ปุ่มเดียว: “เจ๊หญิงสั่งลุย!”)           │
└─────────────────────────┘          └───────────────────────────────────────────────┘
```

## 📦 ติดตั้ง

ต้องมี **Illustrator CC 2019 ขึ้นไป** · Photoshop **2022 (23.3) ขึ้นไป** (ถ้าจะใช้ฝั่ง Photoshop)

ดาวน์โหลดทั้งโฟลเดอร์ `adobe/nesting-cut` มาไว้ในเครื่องก่อน

### Illustrator

**macOS** — ดับเบิลคลิก `install/install-illustrator-mac.command`
(ครั้งแรกถ้าขึ้นว่าเปิดไม่ได้ ให้คลิกขวา > Open)

**Windows** — ดับเบิลคลิก `install/install-illustrator-windows.cmd`

แล้ว **ปิด-เปิด Illustrator ใหม่** → เมนู **Window › Extensions › นัดพอน Nesting Cut**

<details>
<summary>ติดตั้งเอง (ถ้าสคริปต์ใช้ไม่ได้)</summary>

1. เปิดโหมดโหลดแผงที่ยังไม่ได้เซ็นชื่อ (ทำครั้งเดียว)
   - macOS (Terminal): `defaults write com.adobe.CSXS.11 PlayerDebugMode 1` (ทำซ้ำกับเลข 9, 10, 12)
   - Windows (Registry): `HKEY_CURRENT_USER\Software\Adobe\CSXS.11` เพิ่ม String `PlayerDebugMode` = `1` (ทำซ้ำกับ 9, 10, 12)
2. คัดลอกโฟลเดอร์ `nesting-cut` ทั้งโฟลเดอร์ไปไว้ที่
   - macOS: `~/Library/Application Support/Adobe/CEP/extensions/com.nongploy.nestingcut`
   - Windows: `%APPDATA%\Adobe\CEP\extensions\com.nongploy.nestingcut`
3. เปิด Illustrator ใหม่
</details>

ถอนการติดตั้ง: ลบโฟลเดอร์ `com.nongploy.nestingcut` ในที่ข้างบน

### Photoshop

1. ติดตั้ง **UXP Developer Tool** จากแอป Creative Cloud (แท็บ Apps › ค้นคำว่า UXP)
2. เปิด UXP Developer Tool → **Add Plugin** → เลือกไฟล์ `nesting-cut/manifest.json` → กด **Load**
3. ใน Photoshop: เมนู **Plugins › นัดพอน Nesting Cut**

อยากได้ไฟล์ติดตั้งแบบดับเบิลคลิก: ใน UXP Developer Tool กด ••• › **Package** จะได้ไฟล์ `.ccx`
เอาไปดับเบิลคลิกติดตั้งที่เครื่องไหนก็ได้

## 🚀 ใช้งาน

### หน้าตาแผง

แผงเปิดมา **หัวกับปุ่มล่างอยู่กับที่ เลื่อนได้เฉพาะตรงกลาง** และโชว์ **ทีละขั้น** — หน้าหนึ่งมีแค่การ์ดของขั้นนั้น ไม่รก

- **หัวแผง**: โลโก้ · ช่องเลือกเครื่องมือ · **❓ สอน** (เลือกงานที่จะทำ) · **ล้าง** (ล้างงาน)
- **แถบขั้น** (จัดวางดวง / ไดคัทต่อเนื่อง): **1 ชิ้นงาน → 2 กระดาษ → 3 สร้างชีต → 4 ส่งออก** พร้อมคำบอกสั้น ๆ ว่าหน้านี้ต้องทำอะไร
- **ล่างสุด**: **‹ ย้อน** · **ปุ่มส้มปุ่มเดียว** ที่ทำงานของหน้านั้น · ⚡ เจ๊หญิงสั่งลุย! · ข้อความสถานะ
- แผงกว้าง พรีวิวอยู่ช่องซ้ายเห็นตลอด · แผงแคบ พรีวิวอยู่ในหน้า 3
- **ขนาดแผงตายตัว**: ช่องพรีวิว (กรอบ 300 × 400) กว้าง 334 px + ช่องคำสั่งกว้าง 400 px ชิดซ้าย — ขยายแผงแล้วไม่ยืด ไม่เลื่อน
  (แผงกว้างตั้งแต่ 734 px พรีวิวอยู่ข้าง ๆ · แคบกว่านั้นพรีวิวอยู่ในหน้า 3) · หลายแผ่นกด **‹ ›** ดูทีละแผ่น

ปุ่มเป็นสี่เหลี่ยม ตัวอักษรแบบ Mac / iPhone: บน Mac ใช้ฟอนต์ระบบ เครื่องอื่นใช้ Inter + Noto Sans Thai Looped ที่แนบมากับปลั๊กอิน (สัญญาอนุญาต OFL อยู่ใน `assets/fonts/`)

### 👋 งง ไม่รู้จะเริ่มตรงไหน? กด “❓ สอน”

เปิดแผงครั้งแรกจะมีการ์ด **“วันนี้จะทำอะไร?”** ให้กดเลือกงาน เช่น “วางสติ๊กเกอร์หลายแบบลงแผ่นให้ประหยัด” หรือ “ทำตรายางสำหรับเลเซอร์”
แผงจะสลับไปเครื่องมือนั้นให้ — อยากเปลี่ยนงานกด **❓ สอน** มุมขวาบนอีกครั้ง
เครื่องมืออื่นมีเลขบนปุ่มบอกลำดับ เช่น **① วิเคราะห์ / ดูตัวอย่าง → ② ทำมุมโค้ง** และมี “วิธีใช้” พับไว้ในการ์ด

### วิธีใช้ใน 4 ขั้น (จัดวางดวง / ไดคัทต่อเนื่อง)

กด **ปุ่มส้ม** ด้านล่างไปเรื่อย ๆ จนจบ — ขั้นที่เสร็จแล้วเป็น **✓ สีเขียว** · กดเลขขั้นด้านบนเพื่อกลับไปแก้ได้ทุกเมื่อ

| ขั้น | ทำอะไร | ปุ่มส้ม |
|---|---|---|
| **1 ชิ้นงาน** | เลือกภาพ + เส้นไดคัทสีแดงใน Illustrator ให้ครบ (Group ไว้) แล้วกดปุ่มส้ม · ตั้งจำนวนแต่ละแบบ | ดึงชิ้นงานที่เลือก → ถัดไป |
| **2 กระดาษ** | ค่าเริ่มต้น **ใช้อาร์ตบอร์ดที่เปิดอยู่ (เทมเพลตร้าน)** + ☑ **เต็มแผ่น** · หรือเลือกขนาดอื่น · ระยะห่างดวง · ระยะขอบและค่าอื่น ๆ พับไว้ใน “ตั้งค่าละเอียด” | ถัดไป › คำนวณ ดูพรีวิว |
| **3 สร้างชีต** | เข้าหน้านี้แล้วคำนวณให้เอง ดูพรีวิว/จำนวนดวง · ใส่ **ราคากระดาษ** ดูต้นทุนต่อชิ้น (ยังไม่แตะไฟล์งาน) | เรียงลงเทมเพลต / สร้างชีตใน Illustrator |
| **4 ส่งออก** | ติ๊ก PDF / .ai / PLT / DXF / SVG / รูปพรีวิว · ชื่อไฟล์ · โฟลเดอร์ · ปุ่มเลือกเส้นตัด | ส่งออกไฟล์ |

รีบ ๆ ใช้ **⚡ เจ๊หญิงสั่งลุย!** ใต้ปุ่มส้ม — ทำครบทุกขั้นรวดเดียว

> **หัวงาน** (โลโก้ + ชื่องาน วันที่ จำนวนชิ้น ด้านบนแผ่น) **ปิดไว้เป็นค่าเริ่มต้น** — อยากได้ติ๊ก “ใส่หัวงานด้านบน” ในขั้น 2

### 🗂️ เรียงลงเทมเพลตร้าน (Graphtec CE6000 + Cutting Master 5) — ค่าเริ่มต้น

ร้านมีไฟล์เทมเพลต 13 × 19 นิ้ว ที่มี **มาร์กของ Cutting Master 5** + หัวงาน (โลโก้ + QR) อยู่แล้ว — ปลั๊กอินเรียงดวงลงที่ว่างในอาร์ตบอร์ดนั้นเลย ไม่สร้างมาร์กใหม่

1. เปิดไฟล์เทมเพลตใน Illustrator วางสติ๊กเกอร์ 1 ดวง (ภาพ + เส้นไดคัท Group ไว้) ไว้ที่ไหนก็ได้ แล้วคลิกเลือก
2. กด **⚡ เจ๊หญิงสั่งลุย!** (หรือไล่ปุ่มส้ม: ดึงชิ้นงาน → ถัดไป → คำนวณ → **เรียงลงเทมเพลตใน Illustrator**)
3. ส่งเข้า **Cutting Master 5** จาก Illustrator ตามปกติ

- ขนาดกระดาษ = **“ใช้อาร์ตบอร์ดที่เปิดอยู่ (เทมเพลตร้าน)”** (อยู่บนสุด เป็นค่าเริ่มต้น) · **เต็มแผ่น** ติ๊กไว้ = ใส่ดวงแบบแรกให้ได้มากที่สุด ไม่ต้องตั้งจำนวน
- เทมเพลตมีมาร์ก CM5 อยู่แล้ว: วางงานใน **กรอบด้านในของมาร์ก 4 มุม** (เลเยอร์ `reg_*`) แบบไฟล์ “ตัดงานสีดำ” ของร้าน
  · หลบหัวงาน โลโก้ QR และของอื่นบนอาร์ตบอร์ด — รูปทรง/พื้นหลังขนาดเต็มหน้าไม่นับ
- **ป้ายสี่เหลี่ยม** (เส้นตัดเป็นสี่เหลี่ยม หรือไม่มีเส้นตัด): วางชิดกันเป็นตารางเป๊ะ เริ่มแถวใต้หัวงานพอดี
  เส้นตัดเป็นเส้นตรงยาวเส้นเดียวต่อแนว (ป้าย 45 × 20 มม. บน 12.6 × 19 นิ้ว = 6 × 20 = 120 ดวง เส้นตั้ง 7 นอน 21 เหมือนไฟล์)
  — ปิดได้ที่ ☐ “ป้ายสี่เหลี่ยม: วางชิดกัน…” ใต้ “เต็มแผ่น”
- เทมเพลตยังไม่มีมาร์ก: ปลั๊กอินใส่ **มาร์ก L 4 มุมรอบงานแบบไฟล์ CM5 ของร้าน** ให้ (ดูหัวข้อถัดไป)
- เรียงเป็นแถวเรียบร้อย (เยื้องแถวแบบรังผึ้งถ้าได้มากกว่า) แล้วจัดก้อนงานไว้กลางแผ่น
- กดเรียงซ้ำ = **แทนที่ของรอบก่อน** (ลบเฉพาะดวงที่ปลั๊กอินวางไว้) · ดวงต้นแบบที่วางอยู่บนอาร์ตบอร์ดถูกย้ายไปไว้ซ้ายอาร์ตบอร์ด
- ไม่ติ๊กเต็มแผ่น + ตั้งจำนวนหลายแบบ: ถ้าเกินหนึ่งแผ่น แผ่นที่เพิ่มเป็นอาร์ตบอร์ดใหม่พร้อมสำเนาเทมเพลต (มาร์ก + หัวงาน)
- พรีวิว: มาร์กสีดำ หัวงาน/ของบนเทมเพลตสีเทา · ใส่ราคาแผ่นละกี่บาทดูต้นทุนต่อชิ้นได้
- ขั้นส่งออกไม่ต้องทำก็ได้ — ถ้าส่งออก PDF / .ai จะมีเทมเพลตติดไปด้วย

### 📐 ขนาดสำเร็จของร้าน + มาร์ก Graphtec (ไม่ใช้เทมเพลต)

| ชื่อ | ขนาด | หมายเหตุ |
|---|---|---|
| **ขนาดตัดสติ๊กเกอร์งานสีดำ** | 12.6 × 19 นิ้ว | 🔒 ล็อกขนาด |
| **ขนาดงานตัดหน้าร้าน** | 13 × 19 นิ้ว | 🔒 ล็อกขนาด |

เลือกแล้วตั้งหน่วยนิ้ว เครื่องตัด Graphtec และมาร์ก Graphtec ให้เลย (ปลั๊กอินสร้างอาร์ตบอร์ดใหม่ + มาร์กเอง)

**มาร์ก Graphtec CM5** — เหมือนไฟล์ที่ร้านส่ง CE6000: L ที่ **4 มุมของก้อนงาน** มุม L อยู่ที่มุมงาน แขนชี้ออกตามแนวขอบ
รูป L ทึบ ยื่นจากมุม 8.5 มม. หนา 1 มม. (reg_1 “1.00 … 8.00” = เส้นหนา 1 ยาว 8 วัดที่แนวกลาง) สีดำ 4 สี C75 M68 Y67 K90

```
┘                 └      มุม L ห่างดวง 1 มม. (ระยะปลอดรอบมาร์ก)
   ( ดวงสติ๊กเกอร์ )       ปลายแขนห่างขอบกระดาษ ≥ 10 มม. (ห่างขอบ)
┐                 ┌      แก้ได้ใน ตั้งค่าละเอียด › ขนาดมาร์ก
```

มาร์กลงเลเยอร์ชื่อเดียวกับไฟล์ Cutting Master ของร้าน เรียงจากบนลงล่าง:

```
margin 0.000000 0.000000 0.000000 0.000000
color 0 0 0 255 0 0 0 0 255 17.007874
reg_2 0.00 0.00 0.00 0.00 25.00 25.00 25.00 25.00
reg_1 1 1 1.00 1.00 8.00 100.00 1 0 0 0 0.00     ← ตัวมาร์กอยู่ในเลเยอร์นี้
```

ให้มาร์กเหมือนไฟล์ต้นแบบเป๊ะ ๆ (ทำครั้งเดียว):

1. เปิดไฟล์ต้นแบบ Graphtec ของร้าน (ที่มีเลเยอร์ข้างบน) ใน Illustrator แล้วคลิกอาร์ตบอร์ดที่มีมาร์ก
2. ขั้น 2 › กด **จำมาร์กจากไฟล์ที่เปิดอยู่** — ปลั๊กอินจำชื่อเลเยอร์ทั้งหมด + รูปทรง/สี/ตำแหน่งของมาร์กใน reg_1
3. ทุกชีตต่อจากนี้ใช้มาร์กชุดนั้น: แผ่นขนาดเท่าต้นแบบ = ตำแหน่งเดิมเป๊ะ · แผ่นขนาดอื่น = ระยะจากมุมเท่าเดิม · ดวงหลบมาร์กให้เอง

ยังไม่ได้จำ = ใช้มาร์กมาตรฐาน (L 4 มุม ยาว 20 มม. หนา 1 มม. ห่างขอบ 10 มม. — แก้ได้ใน ตั้งค่าละเอียด › ขนาดมาร์ก) · กด **ใช้มาร์กมาตรฐาน** เพื่อเลิกใช้มาร์กที่จำไว้

### 💰 ต้นทุนต่อชิ้น

ขั้น 3 ใส่ **ราคากระดาษ** (เช่น 50 บาท/แผ่น) ใต้ตัวเลขสรุป → โชว์ **ตกชิ้นละ X บาท** และ `2 แผ่น × 50 = 100 บาท · 52 ชิ้น`

- คิดจาก *จำนวนแผ่นที่ใช้ × ราคา ÷ จำนวนชิ้นที่วางได้* (แผ่นสุดท้ายไม่เต็มก็นับเต็มแผ่น) · กระดาษม้วนคิดเป็น บาท/เมตร
- จำราคาแยกตามขนาดกระดาษ — สลับขนาดแล้วราคาเปลี่ยนตาม · แก้ราคาแล้วไม่ต้องคำนวณใหม่
> แล้วช่องชื่องาน ลูกค้า หมายเหตุ โลโก้ จะโผล่ให้กรอก · เปลี่ยนเครื่องตัดแล้วหัวงานไม่เปิดเอง
> ตัวหนังสือไทยในหัวงานจัดสระ/วรรณยุกต์ด้วย World-Ready composer ของ Illustrator แล้วแปลงเป็นเส้น (Outline) ให้ ไม่เพี้ยนตอนส่ง RIP

### แบบที่ 1 — ทำใน Illustrator อย่างเดียว

1. เปิดไฟล์งาน **เลือกชิ้นงาน** บนหน้างาน (กด Shift เลือกได้หลายชิ้น — 1 ชิ้นที่เลือก = 1 แบบ ถ้าชิ้นหนึ่งมีหลายส่วนให้ Group ก่อน)
2. กด **ดึงชิ้นงานที่เลือก** → ใส่ **จำนวน** ของแต่ละแบบ
   (ตั้งชื่อชิ้นงานไว้ล่วงหน้าก็ได้ เช่น `โลโก้ร้าน x20`, `ป้าย ×5`, `สติ๊กเกอร์ 50 ดวง` — ปลั๊กอินอ่านจำนวนให้เอง)
3. ตั้งค่า **วัสดุ & เครื่องตัด** ครั้งแรกครั้งเดียว (จำค่าไว้ให้)
4. กด **เจ๊หญิงสั่งลุย! 🚀** — ปลั๊กอินจะ
   1. สร้างเส้นตัดให้ชิ้นที่ยังไม่มี (วาดเส้น `CutContour` ลงในไฟล์งานเดิมด้วย)
   2. จัดวางตามรูปทรงจริง แสดงพรีวิว ความยาวม้วนที่ใช้ และเปอร์เซ็นต์เนื้อที่
   3. สร้าง **อาร์ตบอร์ดใหม่ต่อท้ายในไฟล์เดิม** (ชิ้นต้นฉบับไม่ถูกย้าย): เลเยอร์ `ไฟล์ปริ้นชิ้นงาน` · `เส้นไดคัท` · `มาร์ก` (· `หัวงาน` ถ้าเปิด)
      (อยากได้เป็นไฟล์แยกเลือก “ไฟล์ใหม่” ในขั้น 3 — ตอนส่งออก PDF/AI ปลั๊กอินสร้างไฟล์ชั่วคราวให้เองเสมอ)
   4. บันทึกไฟล์ลงโฟลเดอร์ `NestingCut` ข้างไฟล์งาน (หรือโฟลเดอร์ที่เลือกไว้)

อยากดูก่อนค่อยสร้าง: ไล่ปุ่มส้มทีละขั้น — ขั้น 3 เห็นพรีวิวก่อนกด **สร้างชีต**

> ชิ้นที่มีเส้นสี Spot ชื่อ `CutContour` อยู่แล้ว ปลั๊กอินใช้เส้นนั้นเลย ไม่สร้างซ้ำ
> (กดลุยซ้ำได้ ไม่เกิดเส้นซ้อน)

### แบบที่ 2 — เริ่มจาก Photoshop (สติ๊กเกอร์รูปภาพ PNG)

1. ใน Photoshop เลือกเลเยอร์สติ๊กเกอร์ (พื้นใส) — 1 เลเยอร์หรือ 1 กลุ่ม = 1 แบบ
2. แผงนัดพอน: ใส่จำนวน · ระยะเส้นตัดห่างขอบ (มม.) · เลือกโฟลเดอร์ → กด **เจ๊หญิงสั่งลุย! ส่งไป Illustrator**
   ปลั๊กอินทำงานในเอกสารชั่วคราว **ไฟล์ PSD ของร้านไม่ถูกแตะ** — ได้รูป PNG แต่ละชิ้น + `nestingcut-pack.json`
3. ใน Illustrator (เปิดไฟล์ใหม่หรือไฟล์ไหนก็ได้) กด **นำเข้าจาก Photoshop** → เลือก `nestingcut-pack.json`
   รูปจะถูกวางพร้อมเส้น `CutContour` และจำนวนชิ้น → กด **เจ๊หญิงสั่งลุย!** ต่อได้เลย

## 🧰 เครื่องมือในแผง (ช่องเลือกเครื่องมือบนหัวแผง)

เครื่องมือทุกตัวอ่านค่าจาก **Selection** ใน Illustrator แล้วสร้างผลกลับลงเอกสารเดิม ไม่ต้องส่งไฟล์สลับไปมาหลายโปรแกรม
ก่อนเริ่มควรบันทึกไฟล์ และเลือกชิ้นงานให้ครบทุกส่วน

| แถบ | ใช้ทำอะไร |
|---|---|
| **จัดวางดวง** (Nesting) | หลายแบบ หลายจำนวน จัดวางตามรูปทรงจริง — ขั้นตอนตามหัวข้อ “ใช้งาน” ข้างบน |
| **ไดคัทต่อเนื่อง** (Sticker · Label) | ต้นแบบดวงเดียวซ้ำเต็มแผ่น + เส้นตัดยาวต่อเนื่อง ยกใบมีดน้อย |
| **ไดคัทตามรูป** (Contour) | สร้างเส้นไดคัทสีแดงรอบเวกเตอร์ / Clipping Mask / รูป PNG-JPG ลงไฟล์เดิม |
| **ทำมุมโค้ง** (CNC Fit) | ปรับมุมใน/มุมนอกของตัวอักษรหรือ Path ตามรัศมีดอกกัด |
| **หาเส้นกลาง** (LED Path) | แนวกลางในตัวอักษรปิดสำหรับวางแถบ LED พร้อมรายงานความยาว/ความกว้าง |
| **บอกขนาด** (Dimension) | เส้นบอกขนาดกว้าง–สูง ตามสเกลไฟล์ 1:1–1:100 |
| **รันนัมเบอร์** (Variable Data) | เลขต่อเนื่องลง Text Frame หรือเลขหน้าอาร์ตบอร์ด |
| **ตรายางเลเซอร์** (Stamp Laser) | เส้นตัดรอบดวงตรา + งานแกะที่กลับด้าน/กลับสีให้ สำหรับเครื่องเลเซอร์ |
| **ปุ่มลัด** (One-key) | ผูกปุ่ม F2–F15 ให้จัดวาง + สร้างชีตด้วยค่าล่าสุดในปุ่มเดียว |

### ไดคัทต่อเนื่อง

1. **เลือกต้นแบบหนึ่งดวง** — ภาพกับเส้นตัด (หรือวัตถุที่จะทำซ้ำ) ให้ครบ → “ดึงชิ้นงานที่เลือก”
2. **ตั้งดวงและหน้ากระดาษ** (ขั้น 2) — ขนาดหน้า ระยะขอบ ·
   รูปทรง `สี่เหลี่ยม` `มุมมน` `วงกลม` `วงรี` `ตามเส้นไดคัทของงาน` · ขนาด `จากงาน` หรือ `กำหนดเอง` · ระยะห่าง ·
   แบบเรียง `เรียงตรง` / `สลับแถว` (วงกลมเรียงแบบรังผึ้งได้ดวงเพิ่ม)
3. ขั้น 3 ดูจำนวนดวง · จำนวนครั้งยกใบมีด · ความยาวเส้นตัด → **สร้างชีต** (อาร์ตบอร์ดใหม่ แยกเลเยอร์พิมพ์/ตัด) → ขั้น 4 **ส่งออก**
   (ชื่อวัสดุ / แกรม พิมพ์บนหัวงาน — กรอกได้เมื่อเปิดหัวงาน)

เส้นตัด: **1 แถว = 1 เส้น** (ยกใบมีดครั้งเดียว) วิ่งตามขอบบนของทุกดวงจนสุดแถวแล้ววนกลับตามขอบล่าง
ช่วงที่ข้ามระหว่างดวงอยู่ในเนื้อกระดาษทิ้งเสมอ · สี่เหลี่ยมชิดกัน (ระยะห่าง 0) ใช้เส้นตรงยาวทั้งแถว/คอลัมน์แทน (ไม่ตัดซ้ำเส้นเดิม)
งานพิมพ์ที่เลยรูปทรงดวงเกินครึ่งหนึ่งของระยะห่างจะมีคำเตือน · สูงสุด 400 ดวงต่อแผ่น

### ไดคัทตามรูปทรง

1. **เลือกเวกเตอร์ รูปภาพ หรือกลุ่ม Clipping Mask** — ข้อความเป็น Live Text ได้ (ปลั๊กอินอ่านจากสำเนา)
2. **เลือกแหล่งขอบ** — `รูปทรงของชิ้นงานทั้งหมด` หรือ `เฉพาะขอบ Clipping Mask` · เผื่อห่าง (Offset) ·
   มุม `มน` / `ตัดมุม` / `มุมแหลม` + จำกัดปลายแหลม (Miter) · ตัดรูข้างในหรือไม่ (งานรูปภาพแนะนำให้ปิด)
3. **กำหนดเลเยอร์แล้วสร้าง** — ค่าเริ่มต้นเลเยอร์ `Die cut` เส้น 0.25 pt สีแดง (หรือสี Spot) อยู่บนสุดของไฟล์

**อ่านรูปภาพ** (PNG / JPG พื้นทึบ): หาสีพื้นจากขอบภาพแล้วลบออก
- `ความต่างสีพื้น` (40) — สีต่างจากพื้นไม่เกินนี้ถือเป็นพื้น
- `ตัดเงาทิ้ง` (50%) — เงาที่ติดพื้น (สีเดียวกับพื้นแต่มืดลง) ถูกลบไปด้วย
- `ความละเอียดเส้น` (100 = ตามขอบละเอียดสุด)

ปลั๊กอินทิ้งเศษจุดเล็ก ข้ามรูที่เล็กเกินกว่าจะตัดได้ และรวมเส้นที่เผื่อระยะแล้วมาชนกันเป็นเส้นเดียว (ได้ดวงเดียว ไม่ใช่ดวงต่อตัวอักษร)
กด **อ่านรูป / ดูตัวอย่าง** ดูเส้นและสรุปก่อน แล้วกด **สร้างเส้นไดคัท** (อ่าน Selection ใหม่ทุกครั้งก่อนวาด)
ภาพ Raster ใช้เวลาวิเคราะห์มากกว่าเวกเตอร์ — ภาพใหญ่หรือพื้นหลังซับซ้อนอาจใช้เวลา 5–10 วินาที ระหว่างนั้น Illustrator จะไม่ตอบสนอง เป็นเรื่องปกติ
ควรเพิ่ม Contrast ให้ตัวแบบแยกจากพื้นหลังชัด และบันทึกงานก่อนเริ่มวิเคราะห์ภาพหนัก

### ◜ ทำมุมโค้ง (CNC Fit)

ปรับมุมในและมุมนอกของตัวอักษรหรือชิ้นเวกเตอร์ให้สัมพันธ์กับรัศมีดอกกัด เหมาะกับงานประกบหน้า–หลังและชิ้นเสียบ

1. **เลือกตัวอักษรหรือ Path** — บันทึกไฟล์ก่อน โดยเฉพาะเมื่อจะแก้ทับของเดิม (ตัวอักษรอ่านจากสำเนาที่ Outline แล้ว)
2. **ใส่รัศมี** — มุมในเริ่มต้น **1.5875 มม.** (= รัศมีดอก 1/8 นิ้ว) · มุมนอกเริ่มต้น 0 · มีรายการขนาดดอกให้เลือก
3. **เลือกผลลัพธ์** — แนะนำ “สร้างสำเนาข้างของเดิม” (วางห่าง 10 มม.) และเปิด **วงกลมตรวจ** จุดที่รัศมีลงไม่ได้
   (ร่องแคบกว่าดอก มุมแหลมจัด ส่วนที่บางกว่าดอก) — วงกลมอยู่บนเลเยอร์ `ตรวจรัศมี`

ตั้งตามดอกจริง: รัศมี = ครึ่งหนึ่งของเส้นผ่านศูนย์กลางดอก
(วิธีคิด: มุมใน = ขยายแล้วหดด้วยรัศมีดอก → ทุกมุมเว้ามีรัศมีที่ดอกเข้าได้ · มุมนอก = หดแล้วขยาย · เส้นตรงยาวคงตรงเป๊ะ)

### ⌇ หาเส้นกลาง (LED Path)

คำนวณแนวกลางภายในตัวอักษรปิดสำหรับวาง LED Strip

1. **เลือกตัวอักษรปิด** — Shape / Path ชัดเจน ไม่มีเส้นเปิดเกินจำเป็น
2. **ตั้งคุณสมบัติแถบไฟ** — กว้าง 6 มม. · รัศมีโค้งต่ำสุด 15 มม. · เว้นจากปลาย 10 มม. (ค่าเริ่มต้น)
3. **ตรวจรายงานแล้ววาด** — จำนวนเส้น ความยาวรวม ความกว้างต่ำสุด–สูงสุด แล้วสร้างลงเลเยอร์ `เส้นกลาง` (เส้นสีเขียว)

พรีวิวมีวงกลมเตือน: 🔴 แคบกว่าแถบไฟ · 🟠 โค้งแคบกว่ารัศมีต่ำสุด · 🔵 กว้างเกินสองเท่าของแถบไฟ
**พื้นที่กว้างมากอาจต้องใช้ 2 แถว** — ปลั๊กอินเตือน แต่เวอร์ชันนี้ยังไม่วาดเส้นคู่ให้อัตโนมัติ ต้องเพิ่มแนวไฟเองหลังตรวจแบบ

### ⇹ ใส่สเกลและเส้นบอกขนาด (Dimension)

วัดกว้าง–สูงแล้ววาดเส้น Dimension แสดงขนาดจริงของงานที่เขียนย่อสเกล โดยไม่เปลี่ยนขนาดวัตถุต้นฉบับ

- **เลือกงาน** — วัด Selection รวม / แต่ละชิ้น / ทั้งสองแบบ · กว้าง สูง หรือทั้งคู่
- **หน่วยและสเกล** — mm, cm, m, inch · 1:1 ถึง 1:100 หรือกำหนดเอง (ขนาดจริง = ขนาดบนไฟล์ × สเกล)
- **รูปแบบ** — ด้านอัตโนมัติ (กว้างบน สูงขวา) หรือกำหนดเอง · สี · ขนาดตัวหนังสือ · น้ำหนักเส้น · ทศนิยม · ระยะห่างจากงาน · เลเยอร์
- **ไม่ลบของเก่าเป็นค่าเริ่มต้น** — ถ้าจะแทนชุดเดิม ติ๊ก “ล้างเส้นบอกขนาดเดิม” ก่อนกดใส่เส้น

### # รันนัมเบอร์ (Variable Data)

1. **เลือกโหมด** — “เติมข้อความที่เลือก” สำหรับป้าย/คูปอง หรือ “เลขหน้าอาร์ตบอร์ด” สำหรับเอกสารหลายหน้า
2. **ตั้งลำดับเลข** — Start · Step (ติดลบได้) · Prefix · Suffix · Padding อัตโนมัติ/กำหนดเอง
3. **การเรียงและรูปแบบ** — โหมดข้อความเรียงตามแถว คอลัมน์ หรือลำดับในเลเยอร์ และเลือกแทนเฉพาะ `{%n}` ได้
   (ข้อความ `บัตรคิว {%n}` → `บัตรคิว 001`) · โหมดหน้ามี 6 ตำแหน่ง ระยะขอบ หน้าเว้น และ Mirror หน้าคู่

รักษารูปแบบเดิมได้ — ใช้สไตล์ข้อความเดิมของ Illustrator หรือกำหนดฟอนต์ ขนาด สี Alignment และ Underline ใหม่
กด **ดูตัวอย่าง** เห็นรายการ “ข้อความเดิม → เลขใหม่” ก่อน **ใส่เลข**

### ◉ เส้นไดคัทงานตรายาง (Laser Stamp)

ทำเส้นตัดรอบดวงตราสำหรับเครื่องเลเซอร์ พร้อมงานแกะ — ธรรมเนียมไฟล์เลเซอร์: **เส้นแดงบาง = ตัดขาด · พื้นดำ = ยิงแกะออก**

1. **เลือกแบบตรายาง** — ตัวอักษร โลโก้ หรือกลุ่มที่จัดไว้ (Live Text ได้) · รวมเป็นตราเดียว หรือแยกแต่ละชิ้นเป็นคนละตรา
2. **ตั้งรูปทรงและระยะขอบ** — สี่เหลี่ยมมุมมน / สี่เหลี่ยม / วงกลม / วงรี / ตามรูปทรงงาน · ระยะจากงานถึงเส้นตัด (2 มม.) · มุมมน
3. **สร้างงานตรายาง** — ได้สำเนาข้างของเดิม (ห่าง 10 มม.): เลเยอร์ `เส้นตัดเลเซอร์` (แดง 0.01 มม.) + `งานแกะเลเซอร์`

- **กลับด้าน (Mirror)** เปิดไว้เป็นค่าเริ่มต้น — ปั๊มออกมาจะอ่านถูก
- **กลับสีสำหรับแกะ** — พื้นในกรอบเป็นสีดำ (ยิงออก) ตัวหนังสือเป็นช่องว่าง (เหลือนูนรับหมึก) รูในตัวอักษรก็ถูกยิงออกถูกต้อง
- ภาพ Raster กลับสีอัตโนมัติไม่ได้ — ปลั๊กอินกลับด้านให้อย่างเดียว (กลับสีใน Photoshop ก่อน)
- ในโปรแกรมเลเซอร์ (LightBurn / RDWorks / LaserCAD) ตั้งสีแดง = Cut และสีดำ = Engrave (Fill)

### 🧹 ล้างงานเก่า

ปุ่ม **ล้างงาน** แถวที่สองของหัวแผง — เปิดกล่องยืนยันในแผงก่อนทุกครั้ง

- ล้างรายการชิ้นงาน ผลคำนวณ และพรีวิวในแผงเสมอ
- เลือกได้: **ลบชีตไดคัทที่นัดพอนสร้างไว้ในไฟล์นี้** — อาร์ตบอร์ดชื่อขึ้นต้น “นัดพอน · แผ่น …” และของบนชีตในเลเยอร์งานพิมพ์/เส้นไดคัท/มาร์ก/หัวงาน
  (ไฟล์ต้องมีอาร์ตบอร์ดอย่างน้อย 1 แผ่น แผ่นสุดท้ายจึงถูกเก็บไว้)
- เลือกได้: **ลบเลเยอร์ผลลัพธ์ของเครื่องมืออื่น** (Die cut, เส้นกลาง, ตรวจรัศมี, Dimension, เลขหน้า, เส้นตัดเลเซอร์, งานแกะเลเซอร์)
- งานต้นฉบับไม่ถูกแตะ · ลบในไฟล์แล้วกด Undo ใน Illustrator ย้อนได้

### ⌨ จัดวางและนำไปใช้ในปุ่มเดียว (One-key)

เลือกชิ้นงานแล้วกดคีย์ลัด นัดพอนจะจัดวางและสร้างชีตไดคัทด้วยค่าล่าสุดทันที

ข้อจำกัดของ Illustrator: ปลั๊กอินจองปุ่มลัดเองไม่ได้ จึงต้องเรียกผ่าน Action และจำกัดเฉพาะ F2–F15

## ⚙️ ค่าตั้งที่ควรรู้

- **ขนาดกระดาษ** — ของร้าน: `ใช้อาร์ตบอร์ดที่เปิดอยู่ (เทมเพลตร้าน)` (ค่าเริ่มต้น) · `ขนาดตัดสติ๊กเกอร์งานสีดำ` (12.6 × 19") · `ขนาดงานตัดหน้าร้าน` (13 × 19") — ขนาดทั่วไป: `A3` (297 × 420 มม., ค่าเริ่มต้น) · `12 × 18"` · `12.5 × 18"` · `13 × 19"` · `กำหนดเอง` (เลือกหน่วยมม./นิ้วได้)
- **ระยะขอบกระดาษ** (ขั้น 2 › ตั้งค่าละเอียด) — แยก บน/ล่าง/ซ้าย/ขวา เริ่มต้น 20 มม. ทุกด้าน **ไม่มีดวงไหนล้ำเข้าไปในขอบ**
- **ระยะห่างระหว่างดวง** — เริ่มต้น 3 มม. วัดจาก *เส้นไดคัทถึงเส้นไดคัท* ต้องมากกว่า 2 เท่าของ Bleed
  ถ้างานพิมพ์เลยเส้นไดคัทเกินครึ่งหนึ่งของระยะห่าง ปลั๊กอินเตือนก่อนสร้างชีต
- **จัดวางตามเส้นไดคัท** — ตำแหน่งดวงคิดจากเส้นไดคัท · สูงสุด **400 ดวงต่อแผ่น** ที่เหลือขึ้นแผ่นใหม่
- **ไม่พบเส้นไดคัท** — ใช้กรอบสี่เหลี่ยมของชิ้นแทน สลับเป็นเรียงแบบตาราง และเตือนให้ตรวจไฟล์
- **เส้นตัดแบบตาราง** — ติ๊กในขั้น 2 › ตั้งค่าละเอียด (ใช้กับการเรียง `ตาราง`): ลากเส้นตรงยาวตามขอบแถว/คอลัมน์ ตัดง่ายทีเดียวทั้งแผ่น
  ถ้าดวงขนาดไม่เท่ากัน เส้นจะเว้นช่วงที่ผ่านกลางดวงอื่น ไม่ตัดดวงขาด
- **เลเยอร์ผลลัพธ์** — ถ้ามีเลเยอร์ `เส้นไดคัท` / `ไฟล์ปริ้นชิ้นงาน` อยู่แล้ว ใช้อันเดิม (ปลดล็อกและเปิดให้มองเห็นให้)
- **เต็มแผ่น** (ขั้น 2 ติ๊กไว้เป็นค่าเริ่มต้น) — ดวงแบบเดียวใส่ให้ได้มากที่สุดในแผ่น (ต้องรู้ความยาวแผ่น เช่น 13×19 นิ้ว หรือเทมเพลต)
  ปลั๊กอินลองเรียงเป็นแถวเยื้องกัน (วงกลมได้แบบรังผึ้ง) และสลับหัวท้าย (สามเหลี่ยม/หัวใจ) แล้วเทียบกับวางทีละดวง
  เอาแบบที่ได้ดวงมากกว่า — ผลบอก “ได้ N ดวง ต่อ 1 แผ่น · ดวงขนาด W × H มม.”
- **รูปแบบการเรียง** — `ตามรูปทรง` ได้ดวงเยอะกว่า · `ตาราง` เรียงแถว-คอลัมน์ตามกรอบของชิ้น (ตัดตามเส้นจริงเหมือนเดิม)
- **เส้นไดคัท** — ต้องเป็น *เส้นขอบ (stroke)* สี Spot ชื่อที่ตั้งไว้ / ชื่อที่มี cut, die, thru, kiss
  หรือเส้นขอบสีแดง (RGB, CMYK M+Y) — พื้นสีแดงถือเป็นงานพิมพ์ ในไฟล์เลย์เอาต์เส้นไดคัทแยกไปอยู่เลเยอร์
  `เส้นไดคัท` งานพิมพ์อยู่เลเยอร์ `ไฟล์ปริ้นชิ้นงาน` (เปลี่ยนชื่อได้ในขั้น 2 › ตั้งค่าละเอียด)

- **ความละเอียด** — `ปกติ (1 มม.)` เร็วและแน่นพอสำหรับงานทั่วไป · `แน่น (0.5 มม.)` ชิดขึ้นเล็กน้อยแต่ช้ากว่า ~4 เท่า
  (ระยะห่างจริงระหว่างชิ้นไม่ต่ำกว่าที่ตั้งเสมอ ความละเอียดมีผลแค่ว่าวางชิดได้แค่ไหน)
- **หมุนชิ้นงาน** — `ไม่หมุน` · `180°` · `90°` · `อิสระ` — ทุก 90° เหมาะกับงานส่วนใหญ่ · วัสดุมีลาย/ทิศ (เคฟล่า เงินขนแมว) เลือก “ไม่หมุน” หรือติ๊ก “หมุน” ออกเป็นรายชิ้น
- **ม้วน vs แผ่น** — ช่อง “ยาว” ว่าง = ม้วน (ตัดความยาวเท่าที่ใช้จริง สูงสุด 5.5 ม./แผ่นเพราะ Illustrator ทำอาร์ตบอร์ดยาวกว่านั้นไม่ได้) · ใส่ตัวเลข = แผ่นขนาดคงที่ เกินแล้วขึ้นแผ่นใหม่
- **ชิ้นที่ยังไม่มีเส้นตัด** — `สร้างตามขอบงาน` (ค่าเริ่มต้น) · `ตามเวกเตอร์` ใช้กับงานไวนิลตัวหนังสือ/โลโก้เวกเตอร์ล้วน · `กรอบสี่เหลี่ยม` ใช้กับฉลาก/นามบัตร
