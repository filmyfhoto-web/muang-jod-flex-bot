# น้องพลอย Nesting Cut ✂️

ปลั๊กอิน **Adobe Illustrator** + **Photoshop** สำหรับร้านสติ๊กเกอร์/ป้าย:
จัดวางชิ้นงาน **ตามรูปทรงจริง** (true-shape nesting) แล้วส่งออกไฟล์ **สั่งเครื่องตัด** ได้ในคลิกเดียว — *เจ๊หญิงสั่งลุย!*

**Nesting · Cut-Line · Marks · Header Logo**

โทนสีกรม + ส้มอิฐ · โลโก้อยู่ที่ `assets/logo.svg` (ตัวอักษรเป็นเส้นแล้ว เปิดแก้ใน Illustrator ได้ ไม่ต้องมีฟอนต์)

| | ทำอะไร |
|---|---|
| ✂️ **Cut-Line** | ชิ้นไหนยังไม่มีเส้นตัด สร้างให้เอง: ตามขอบงาน (อ่านจากความโปร่งใส ใช้ได้ทั้งเวกเตอร์ รูป PNG ตัวหนังสือ) เว้นระยะได้ · ตัดตามเส้นเวกเตอร์ · หรือกรอบสี่เหลี่ยม (มุมมน) — เป็นเส้นสี Spot `CutContour` ที่ RIP ทุกเจ้าอ่านได้ |
| 🧩 **Nesting** | จัดวางตามรูปทรงจริง หมุนได้ 90°/45°/15° เว้นระยะห่างชิ้นตามตั้ง กันสีล้น (bleed) ทับชิ้นข้าง ๆ ลองหลายลำดับแล้วเลือกแบบที่ใช้ม้วนสั้นที่สุด ม้วนยาวเกินขึ้นแผ่นใหม่ให้เอง |
| 🎯 **Marks** | มาร์กสำหรับพิมพ์แล้วตัด: จุดวงกลม / สี่เหลี่ยม / L 4 มุม / แบบ Silhouette + มาร์กกลางสำหรับงานยาว — ชิ้นงานหลบมาร์กให้อัตโนมัติ |
| 🏷️ **Header Logo** | หัวงานบนแผ่น: โลโก้ร้าน + ชื่องาน ลูกค้า วันที่ จำนวนชิ้น ขนาดแผ่น |
| 📤 **ส่งออก** | PDF (ให้ RIP พิมพ์+ตัด) · .ai · **PLT** (HP-GL) · **DXF** · **SVG** · รูปพรีวิวส่งลูกค้าทางไลน์ |

```
Photoshop (เลเยอร์ PNG)                      Illustrator
┌─────────────────────────┐   แพ็ก   ┌───────────────────────────────────────────────┐
│ เลือกเลเยอร์ → เส้นตัด  │ ───────▶ │ ดึงชิ้นงาน → เส้นตัด → จัดวาง → เลย์เอาต์ → ส่งออก │ ──▶ RIP / เครื่องตัด
│ ตามขอบ → ส่ง Illustrator│  (json)  │        (ปุ่มเดียว: “เจ๊หญิงสั่งลุย!”)           │
└─────────────────────────┘          └───────────────────────────────────────────────┘
```

## 📦 ติดตั้ง

ต้องมี **Illustrator CC 2019 ขึ้นไป** · Photoshop **2022 (23.3) ขึ้นไป** (ถ้าจะใช้ฝั่ง Photoshop)

ดาวน์โหลดทั้งโฟลเดอร์ `adobe/nesting-cut` มาไว้ในเครื่องก่อน

### Illustrator

**macOS** — ดับเบิลคลิก `install/install-illustrator-mac.command`
(ครั้งแรกถ้าขึ้นว่าเปิดไม่ได้ ให้คลิกขวา > Open)

**Windows** — ดับเบิลคลิก `install/install-illustrator-windows.cmd`

แล้ว **ปิด-เปิด Illustrator ใหม่** → เมนู **Window › Extensions › น้องพลอย Nesting Cut**

<details>
<summary>ติดตั้งเอง (ถ้าสคริปต์ใช้ไม่ได้)</summary>

1. เปิดโหมดโหลดแผงที่ยังไม่ได้เซ็นชื่อ (ทำครั้งเดียว)
   - macOS (Terminal): `defaults write com.adobe.CSXS.11 PlayerDebugMode 1` (ทำซ้ำกับเลข 9, 10, 12)
   - Windows (Registry): `HKEY_CURRENT_USER\Software\Adobe\CSXS.11` เพิ่ม String `PlayerDebugMode` = `1` (ทำซ้ำกับ 9, 10, 12)
2. คัดลอกโฟลเดอร์ `nesting-cut` ทั้งโฟลเดอร์ไปไว้ที่
   - macOS: `~/Library/Application Support/Adobe/CEP/extensions/com.nongploy.nestingcut`
   - Windows: `%APPDATA%\Adobe\CEP\extensions\com.nongploy.nestingcut`
3. เปิด Illustrator ใหม่
</details>

ถอนการติดตั้ง: ลบโฟลเดอร์ `com.nongploy.nestingcut` ในที่ข้างบน

### Photoshop

1. ติดตั้ง **UXP Developer Tool** จากแอป Creative Cloud (แท็บ Apps › ค้นคำว่า UXP)
2. เปิด UXP Developer Tool → **Add Plugin** → เลือกไฟล์ `nesting-cut/manifest.json` → กด **Load**
3. ใน Photoshop: เมนู **Plugins › น้องพลอย Nesting Cut**

อยากได้ไฟล์ติดตั้งแบบดับเบิลคลิก: ใน UXP Developer Tool กด ••• › **Package** จะได้ไฟล์ `.ccx`
เอาไปดับเบิลคลิกติดตั้งที่เครื่องไหนก็ได้

## 🚀 ใช้งาน

### วิธีใช้ใน 4 ขั้นตอน

| | |
|---|---|
| **01 เลือกชิ้นงาน** | เลือกภาพและเส้นไดคัทสีแดงของสติ๊กเกอร์หนึ่งดวงให้ครบ (Group ไว้) แล้วกด “ดึงชิ้นงานที่เลือก” |
| **02 ตั้งค่ากระดาษ** | เลือกขนาดกระดาษ ระยะขอบ ระยะห่าง รูปแบบเรียง และมุมหมุน (อยากได้ดวงเยอะสุดติ๊ก “เต็มแผ่น”) |
| **03 กด “คำนวณ”** | ดูจำนวนดวงและตัวอย่างบนจอ (แผงกว้างพรีวิวอยู่ช่องซ้ายคู่กับคำสั่ง) โดยยังไม่แตะเอกสารต้นฉบับ |
| **04 สร้างชีตไดคัท** | สร้างสำเนาในไฟล์ใหม่ พร้อมแยกเลเยอร์งานพิมพ์และเส้นตัด แล้วกด “ส่งออก” — หรือกด **เจ๊หญิงสั่งลุย!** ทำครบรวดเดียว |

### แบบที่ 1 — ทำใน Illustrator อย่างเดียว

1. เปิดไฟล์งาน **เลือกชิ้นงาน** บนหน้างาน (กด Shift เลือกได้หลายชิ้น — 1 ชิ้นที่เลือก = 1 แบบ ถ้าชิ้นหนึ่งมีหลายส่วนให้ Group ก่อน)
2. กด **ดึงชิ้นงานที่เลือก** → ใส่ **จำนวน** ของแต่ละแบบ
   (ตั้งชื่อชิ้นงานไว้ล่วงหน้าก็ได้ เช่น `โลโก้ร้าน x20`, `ป้าย ×5`, `สติ๊กเกอร์ 50 ดวง` — ปลั๊กอินอ่านจำนวนให้เอง)
3. ตั้งค่า **วัสดุ & เครื่องตัด** ครั้งแรกครั้งเดียว (จำค่าไว้ให้)
4. กด **เจ๊หญิงสั่งลุย! 🚀** — ปลั๊กอินจะ
   1. สร้างเส้นตัดให้ชิ้นที่ยังไม่มี (วาดเส้น `CutContour` ลงในไฟล์งานเดิมด้วย)
   2. จัดวางตามรูปทรงจริง แสดงพรีวิว ความยาวม้วนที่ใช้ และเปอร์เซ็นต์เนื้อที่
   3. สร้าง **ไฟล์เลย์เอาต์ใหม่** (ไฟล์งานเดิมไม่ถูกย้ายชิ้น): เลเยอร์ `ชิ้นงาน` · `มาร์ก` · `หัวงาน`
   4. บันทึกไฟล์ลงโฟลเดอร์ `NestingCut` ข้างไฟล์งาน (หรือโฟลเดอร์ที่เลือกไว้)

อยากดูก่อนค่อยสร้าง: กด **คำนวณ** → ปรับค่า → **สร้างชีตไดคัท** → **ส่งออก**

> ชิ้นที่มีเส้นสี Spot ชื่อ `CutContour` อยู่แล้ว ปลั๊กอินใช้เส้นนั้นเลย ไม่สร้างซ้ำ
> (กดลุยซ้ำได้ ไม่เกิดเส้นซ้อน)

### แบบที่ 2 — เริ่มจาก Photoshop (สติ๊กเกอร์รูปภาพ PNG)

1. ใน Photoshop เลือกเลเยอร์สติ๊กเกอร์ (พื้นใส) — 1 เลเยอร์หรือ 1 กลุ่ม = 1 แบบ
2. แผงน้องพลอย: ใส่จำนวน · ระยะเส้นตัดห่างขอบ (มม.) · เลือกโฟลเดอร์ → กด **เจ๊หญิงสั่งลุย! ส่งไป Illustrator**
   ปลั๊กอินทำงานในเอกสารชั่วคราว **ไฟล์ PSD ของร้านไม่ถูกแตะ** — ได้รูป PNG แต่ละชิ้น + `nestingcut-pack.json`
3. ใน Illustrator (เปิดไฟล์ใหม่หรือไฟล์ไหนก็ได้) กด **นำเข้าจาก Photoshop** → เลือก `nestingcut-pack.json`
   รูปจะถูกวางพร้อมเส้น `CutContour` และจำนวนชิ้น → กด **เจ๊หญิงสั่งลุย!** ต่อได้เลย

### ✅ เช็กครั้งแรกก่อนใช้จริง (ทำครั้งเดียวต่อเครื่อง)

1. **มาร์ก** — ขนาด/ระยะห่างขอบในแผง (หัวข้อ 4) ต้องตรงกับที่ตั้งในซอฟต์แวร์เครื่องตัด ค่าที่ให้มาเป็นค่าเริ่มต้นโดยประมาณ
2. **PLT** — ตัดชิ้นเล็ก ๆ ทดลองก่อน ถ้างานออกมาหมุนหรือกลับด้าน ให้สลับ “แกน PLT” (หัวข้อ 6)
3. **ระยะห่างชิ้น** — ถ้างานมีสีเลยเส้นตัด (bleed) เปิด “เผื่อ bleed” ไว้ (ค่าเริ่มต้นเปิดอยู่) สีจะไม่ล้นทับชิ้นข้าง ๆ

## ⚙️ ค่าตั้งที่ควรรู้

- **เต็มแผ่น** (หัวข้อ 2) — ดวงแบบเดียวใส่ให้ได้มากที่สุดในแผ่น (ต้องใส่ความยาวแผ่น เช่น 13×19 นิ้ว)
  ปลั๊กอินลองเรียงเป็นแถวเยื้องกัน (วงกลมได้แบบรังผึ้ง) และสลับหัวท้าย (สามเหลี่ยม/หัวใจ) แล้วเทียบกับวางทีละดวง
  เอาแบบที่ได้ดวงมากกว่า — ผลบอก “ได้ N ดวง ต่อ 1 แผ่น · ดวงขนาด W × H มม.”
- **รูปแบบการเรียง** — `ตามรูปทรง` ได้ดวงเยอะกว่า · `ตาราง` เรียงแถว-คอลัมน์ตามกรอบของชิ้น (ตัดตามเส้นจริงเหมือนเดิม)
- **เส้นไดคัท** — ต้องเป็น *เส้นขอบ (stroke)* สี Spot ชื่อที่ตั้งไว้ / ชื่อที่มี cut, die, thru, kiss
  หรือเส้นขอบสีแดง (RGB, CMYK M+Y) — พื้นสีแดงถือเป็นงานพิมพ์ ในไฟล์เลย์เอาต์เส้นไดคัทแยกไปอยู่เลเยอร์
  `เส้นไดคัท` งานพิมพ์อยู่เลเยอร์ `ไฟล์ปริ้นชิ้นงาน` (เปลี่ยนชื่อได้ในหัวข้อ 3)

- **ความละเอียด** — `ปกติ (1 มม.)` เร็วและแน่นพอสำหรับงานทั่วไป · `แน่น (0.5 มม.)` ชิดขึ้นเล็กน้อยแต่ช้ากว่า ~4 เท่า
  (ระยะห่างจริงระหว่างชิ้นไม่ต่ำกว่าที่ตั้งเสมอ ความละเอียดมีผลแค่ว่าวางชิดได้แค่ไหน)
- **หมุนชิ้นงาน** — ทุก 90° เหมาะกับงานส่วนใหญ่ · วัสดุมีลาย/ทิศ (เคฟล่า เงินขนแมว) เลือก “ห้ามหมุน” หรือติ๊ก “หมุน” ออกเป็นรายชิ้น
- **ม้วน vs แผ่น** — ช่อง “ยาว” ว่าง = ม้วน (ตัดความยาวเท่าที่ใช้จริง สูงสุด 5.5 ม./แผ่นเพราะ Illustrator ทำอาร์ตบอร์ดยาวกว่านั้นไม่ได้) · ใส่ตัวเลข = แผ่นขนาดคงที่ เกินแล้วขึ้นแผ่นใหม่
- **ชิ้นที่ยังไม่มีเส้นตัด** — `สร้างตามขอบงาน` (ค่าเริ่มต้น) · `ตามเวกเตอร์` ใช้กับงานไวนิลตัวหนังสือ/โลโก้เวกเตอร์ล้วน · `กรอบสี่เหลี่ยม` ใช้กับฉลาก/นามบัตร
