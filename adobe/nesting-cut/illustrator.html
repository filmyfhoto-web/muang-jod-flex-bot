โหมดทดลอง — หน้านี้ไม่ได้เปิดอยู่ใน Illustrator จึงใช้ชิ้นงานตัวอย่างแทน ลองกด “เจ๊หญิงสั่งลุย!” ได้เลย หรือเพิ่มรูป PNG พื้นใสของร้านเองก็ได้ ไฟล์ตัด (PLT / DXF / SVG) จะดาวน์โหลดลงเครื่อง
วิธีใช้ใน 4 ขั้นตอน
  1. เลือกชิ้นงานเลือกภาพและเส้นไดคัทสีแดงของสติ๊กเกอร์หนึ่งดวงให้ครบ (Group ไว้) แล้วกด “ดึงชิ้นงานที่เลือก”
  2. ตั้งค่ากระดาษเลือกขนาดกระดาษ ระยะขอบ ระยะห่าง รูปแบบเรียง และมุมหมุน (หัวข้อ 2)
  3. กด “คำนวณ”ดูจำนวนดวงและตัวอย่างบนจอ โดยยังไม่แตะเอกสารต้นฉบับ
  4. สร้างชีตไดคัทสร้างสำเนาในไฟล์ใหม่ พร้อมแยกเลเยอร์งานพิมพ์และเส้นตัด — หรือกด “เจ๊หญิงสั่งลุย!” ทำครบทุกขั้นรวดเดียวพร้อมส่งออก

✂ ไดคัทตามรูปทรง

สร้างเส้น Stroke สีแดงตาม Silhouette จริงของเวกเตอร์ ขอบ Clipping Mask หรือรูปภาพ PNG / JPG พร้อม Offset และรวมเส้นที่สัมผัสกันเป็นเส้นเดียว — บันทึกไฟล์ก่อน แล้วเลือกชิ้นงานให้ครบทุกส่วน

  1. เลือกเวกเตอร์ รูปภาพ หรือกลุ่ม Clipping Maskข้อความเป็น Live Text ได้ ปลั๊กอินอ่านจากสำเนา ไม่แตะงานเดิม
  2. เลือกแหล่งขอบทุกชิ้นงานหรือเฉพาะ Clipping Mask แล้วตั้ง Offset มุม มน / ตัดมุม / แหลม และการตัดรูด้านใน
  3. กำหนดเลเยอร์แล้วสร้างค่าเริ่มต้นคือเลเยอร์ “Die cut” เส้น 0.25 pt อยู่บนสุดของไฟล์

เส้นไดคัท

อ่านรูปภาพ

ภาพ Raster ใช้เวลาวิเคราะห์มากกว่าเวกเตอร์ — ภาพใหญ่หรือพื้นหลังซับซ้อนอาจใช้เวลาประมาณ 5–10 วินาที ระหว่างนั้น Illustrator จะไม่ตอบสนอง เป็นเรื่องปกติ รอจนเสร็จ

  • เพิ่ม Contrast ให้ตัวแบบแยกจากพื้นหลังชัด ๆ ก่อนอ่าน
  • บันทึกงานก่อนเริ่มวิเคราะห์ภาพหนัก

เลเยอร์และเส้น

◜ ทำมุมโค้ง CNC FIT

ปรับมุมในและมุมนอกของตัวอักษรหรือชิ้นเวกเตอร์ให้สัมพันธ์กับรัศมีดอกกัด เหมาะกับงานประกบหน้า–หลังและชิ้นเสียบ

  1. เลือกตัวอักษรหรือ Pathบันทึกไฟล์ก่อน โดยเฉพาะเมื่อจะเลือกแก้ทับของเดิม — ตัวอักษรอ่านจากสำเนาที่ Outline แล้ว
  2. ใส่รัศมีมุมในเริ่มต้น 1.5875 มม. = รัศมีดอก 1/8 นิ้ว · มุมนอกเริ่มต้น 0 (ไม่โค้ง)
  3. เลือกผลลัพธ์แนะนำ “สร้างสำเนาข้างของเดิม” และเปิดวงกลมตรวจจุดที่รัศมีลงไม่ได้

ตั้งตามดอกจริง — ใช้ดอกขนาดอื่น ให้ใส่รัศมีเท่ากับครึ่งหนึ่งของเส้นผ่านศูนย์กลางดอก มุมที่ออกแบบจะสัมพันธ์กับเครื่องมือผลิต

เลือกตัวอักษรหรือ Path แล้วกดวิเคราะห์

⌇ หาเส้นกลาง LED PATH

คำนวณแนวกลางภายในตัวอักษรปิดสำหรับวาง LED Strip พร้อมสรุปความยาว และเตือนบริเวณที่แคบหรือโค้งเกินข้อกำหนด

  1. เลือกตัวอักษรปิดใช้ชิ้นงานที่เป็น Shape / Path ชัดเจน ไม่มีเส้นเปิดเกินจำเป็น
  2. ตั้งคุณสมบัติแถบไฟความกว้างเริ่มต้น 6 มม. · รัศมีโค้งต่ำสุด 15 มม. · เว้นจากปลาย 10 มม.
  3. ตรวจรายงานแล้ววาดดูจำนวนเส้น ความยาวรวม ความกว้างต่ำสุด–สูงสุด แล้วสร้างลงเลเยอร์ “เส้นกลาง”

! พื้นที่กว้างมากอาจต้องใช้ 2 แถว — แจ้งเตือนเมื่อความกว้างมากกว่าสองเท่าของแถบไฟ แต่เวอร์ชันนี้ยังไม่วาดเส้นคู่ให้อัตโนมัติ ต้องเพิ่มแนวไฟเองหลังตรวจแบบ

เลือกตัวอักษรปิดแล้วกดวิเคราะห์

⇹ ใส่สเกลและเส้นบอกขนาด DIMENSION

วัดกว้าง–สูงแล้ววาดเส้น Dimension แสดงขนาดจริงของงานที่เขียนย่อสเกลได้ โดยไม่เปลี่ยนขนาดวัตถุต้นฉบับ

ไม่ลบของเก่าเป็นค่าเริ่มต้น — ถ้าต้องการแทนชุด Dimension เดิม ให้ติ๊ก “ล้างเส้นบอกขนาดเดิม” ก่อนกดใส่เส้น

เลือกงานแล้วกดใส่เส้นบอกขนาด

# รันนัมเบอร์ VARIABLE DATA

เติมเลขต่อเนื่องลง Text Frame ที่เลือก หรือสร้างเลขหน้าบนอาร์ตบอร์ดทุกหน้า รองรับเลขเริ่ม ช่วงก้าว Prefix / Suffix และเลขศูนย์นำหน้า

    เลือก Text Frame (หรือเปิดไฟล์หลายอาร์ตบอร์ด) แล้วกดดูตัวอย่าง

    ⌨ จัดวางและนำไปใช้ในปุ่มเดียว ONE-KEY WORKFLOW

    เลือกชิ้นงานแล้วกดคีย์ลัด นัดพอนจะจัดวางและสร้างชีตไดคัทด้วยค่าล่าสุดของแถบ “จัดวางดวง” (หรือ “ไดคัทต่อเนื่อง” ถ้าเปิดค้างไว้) ทันที

    1. เลือกปุ่ม F2–F15เพิ่ม Cmd / Ctrl หรือ Shift ได้
    2. กด “วิธีตั้งค่า”แผงติดตั้งสคริปต์ “NudPon Quick Nest” แล้วแสดงขั้นตอน
    3. สร้าง Illustrator Actionใช้ Insert Menu Item เรียก File → Scripts → NudPon Quick Nest แล้วตั้งปุ่มลัดให้ Action

    ข้อจำกัดของ Illustrator — ปลั๊กอินจองปุ่มลัดเองไม่ได้ จึงต้องเรียกผ่าน Action และจำกัดเฉพาะ F2–F15 ต้องเปิดแผงนัดพอนอย่างน้อยหนึ่งครั้งหลังเปิด Illustrator

    เลือกชิ้นงานบนหน้างาน (กี่ชิ้นก็ได้) แล้วกด “ดึงชิ้นงานที่เลือก” — ตั้งจำนวนไว้ในชื่อได้ เช่น “โลโก้ร้าน x20”

      ★ ไดคัทต่อเนื่อง STICKER · LABEL

      วางสติ๊กเกอร์หนึ่งต้นแบบซ้ำเต็มชีต แล้วสร้างแนวตัดยาวต่อเนื่อง ลดจำนวนครั้งที่เครื่องยกใบมีด เหมาะกับงานฉลากจำนวนมาก

      1. เลือกต้นแบบหนึ่งดวงเลือกภาพกับเส้นตัดหรือวัตถุที่ต้องการทำซ้ำให้ครบ แล้วกด “ดึงชิ้นงานที่เลือก”
      2. ตั้งวัสดุและหน้ากระดาษชื่อวัสดุ แกรม ขนาดหน้า ระยะขอบ (หัวข้อ 2) รูปทรง ขนาด ระยะห่าง และแบบเรียงตรงหรือสลับแถว
      3. ตรวจตัวอย่างแล้วสร้างดูจำนวนดวงและจำนวนครั้งยกใบมีด จากนั้นกด “สร้างชีตไดคัท”

      ความต่อเนื่องของเส้น: 1 แถว = 1 เส้น (ยกใบมีดครั้งเดียว) เส้นวิ่งตามขอบบนไปจนสุดแถวแล้ววนกลับตามขอบล่าง ช่วงที่ข้ามระหว่างดวงอยู่ในเนื้อกระดาษทิ้ง — สี่เหลี่ยมชิดกัน (ระยะห่าง 0) ใช้เส้นตรงยาวทั้งแถว/คอลัมน์แทน ดูจำนวนครั้งยกใบมีดในพรีวิวก่อนสร้างจริง

      2 หน้ากระดาษ & การวางดวง

      3 เส้นตัด (Cut-Line)
      • เส้นไดคัทต้องเป็น เส้นขอบ (stroke) — สีแดงที่เป็นพื้น (fill) ถือว่าเป็นงานพิมพ์
      • รับสี Spot ชื่อที่ตั้งไว้ หรือชื่อที่มีคำว่า cut / die / thru / kiss และสีแดง RGB / CMYK (M+Y)
      • ชิ้นที่ยังไม่มีเส้นตัด สร้างให้ตามแบบที่เลือกข้างบน — ชิ้นที่มีอยู่แล้วใช้เส้นเดิม ไม่สร้างซ้ำ
      • ถ้าไม่พบเส้นไดคัท จะใช้กรอบสี่เหลี่ยมของชิ้นงานแทน เรียงแบบตาราง และเตือนก่อนสร้างชีต
      • ถ้ามีเลเยอร์ชื่อนี้อยู่แล้ว ใช้อันเดิม พร้อมปลดล็อกและเปิดการมองเห็นให้
      • ดวงต้นฉบับไม่ถูกย้าย — สร้างสำเนาใหม่ทั้งหมดบนอาร์ตบอร์ดใหม่ · การวางยึดเส้นไดคัท ไม่ใช่ขอบภาพ · สูงสุด 400 ดวงต่อแผ่น
