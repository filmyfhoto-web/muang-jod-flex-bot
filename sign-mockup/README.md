# นัดพอน Sign Mockup — จำลองป้ายให้ลูกค้าเห็นก่อนสั่งผลิต

เว็บแอปเล็ก ๆ สำหรับหน้าร้าน: ใส่ไฟล์งาน (หรือพิมพ์ข้อความเร็ว ๆ) เลือกชนิดป้ายกับขนาด
แล้วได้ภาพจำลองป้ายติดอยู่บนผนัง หน้าร้าน หรือรั้ว พร้อมเส้นบอกขนาด คนยืนเทียบ และราคา
บันทึกเป็นรูป JPG ส่งลูกค้าทาง LINE ได้ทันที

เปิดใช้: **`https://<โดเมนบอต>/sign/`** (เสิร์ฟจากเซิร์ฟเวอร์บอตตัวเดิม ไม่ต้องตั้งค่าเพิ่ม)
แล้วกดปุ่ม **ติดตั้งโปรแกรม** มุมขวาบน จะได้ไอคอนบนคอม/มือถือ เปิดได้แม้ไม่มีเน็ต

## ใช้งาน 4 ขั้น

| ขั้น | ทำอะไร |
| --- | --- |
| 1 งานออกแบบ | ใส่ไฟล์ JPG/PNG (ลากมาวาง หรือ Ctrl+V ก็ได้) — ป้ายติดผนังจะปรับความสูงตามสัดส่วนรูปให้เอง · ยังไม่มีงาน → พิมพ์ข้อความ เลือกชุดสี |
| 2 ชนิดและขนาด | ไวนิลตาไก่ · ไวนิลขึงโครง · โฟมบอร์ด · อะคริลิค · โรลอัพ · X-Stand — กรอกกว้าง × สูงเป็นซม. หรือกดขนาดสำเร็จรูป (A3–A0, 80×200 ฯลฯ) |
| 3 ฉาก | พื้นเรียบ · ผนังปูน · ผนังอิฐ · หน้าร้านตึกแถว · รั้วกลางแจ้ง · **รูปหน้าร้านลูกค้า** (ลากจุดส้ม 4 มุมให้ตรงที่จะติด) — เปิด/ปิดคนยืนเทียบ 170 ซม. และเส้นบอกขนาด |
| 4 ราคาและส่งออก | ราคาต่อ ตร.ม. (ป้ายแผ่น) หรือต่อชุด (ขาตั้ง) × จำนวน → ยอดรวม · ชื่อลูกค้า ชื่อร้าน เบอร์ โลโก้ ลงแถบใต้ภาพ · กด **บันทึกรูปส่งลูกค้า** |

- ราคาไม่ใส่ = ไม่โชว์ราคาบนภาพ · ป้ายแผ่นคิด พื้นที่ × ราคาต่อ ตร.ม. แล้ว **ปัดเศษขึ้นเป็นบาท** ต่อชิ้น
- ราคาต่อ ตร.ม. แยกจำไว้ทีละชนิดป้าย ชื่อร้าน/เบอร์/โลโก้ก็จำไว้ในเครื่อง (ไฟล์งานกับรูปลูกค้าไม่เก็บ)
- มือถือ: ในหน้าต่างบันทึกรูป กด **แชร์** ส่งเข้า LINE ได้เลย หรือกดค้างที่รูปแล้วบันทึก

## ไฟล์

| ไฟล์ | หน้าที่ |
| --- | --- |
| `core.js` | ตรรกะล้วน (ขนาด ราคา ตาไก่ กล้อง โฮโมกราฟี) — เทสต์ที่ `tests/signMockup.test.js` |
| `render.js` | วาดฉากและตัวป้ายบน canvas ตามขนาดจริงเป็นเซนติเมตร (ไม่มีรูปฉากให้โหลด) |
| `app.js`, `index.html`, `app.css` | หน้าจอ 4 ขั้น ปุ่มติดตั้ง ส่งออกรูป |
| `manifest.webmanifest`, `sw.js`, `icons/` | ติดตั้งเป็นแอป + ใช้ออฟไลน์ — แก้ไฟล์แอปแล้วให้เลื่อน `VERSION` ใน `sw.js` |

ไม่ต้อง build อะไร เป็นไฟล์นิ่งล้วน จะเปิดจากที่อื่น (GitHub Pages, Netlify, Vercel) ก็ได้
แค่ต้องเป็น https ปุ่มติดตั้งถึงจะขึ้น · ฟอนต์ Kanit / IBM Plex Sans Thai โหลดจาก Google Fonts
