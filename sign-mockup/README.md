# นัดพอน Sign Mockup — จำลองป้ายให้ลูกค้าเห็นก่อนสั่งผลิต

เว็บแอปสำหรับหน้าร้าน: ใส่ไฟล์งาน (หรือพิมพ์ข้อความเร็ว ๆ) เลือกชนิดป้ายกับขนาด
แล้วได้ **ภาพ 3 มิติ** ของป้ายจริงติดอยู่บนผนัง หน้าร้าน หรือรั้ว — ลากหมุนดูรอบ ๆ ซูมเข้าออกได้
มีเส้นบอกขนาด คนยืนเทียบ ราคา และโหมดกลางคืน บันทึกเป็นรูป JPG ส่งลูกค้าทาง LINE ได้ทันที

**โลโก้ร้าน NATTAPRON Color Lab & Printing** อยู่ที่แถบบน ไอคอนแอป แถบใต้ภาพ และหัวใบเสนอราคา (เปลี่ยนเป็นโลโก้อื่น/เอาออกได้ในขั้น 4)
· **คนยืนเทียบขนาด 170 ซม.** เป็นรูปการ์ตูนเจ้าของร้าน (เสื้อโปโลกรมท่าปกแดงโลโก้ NTP ยืนปล่อยแขน) ในฉาก 3 มิติเป็นป้ายรูปคนที่หันหน้าเข้ากล้องเสมอ
  มีเงาตามรูปร่าง กลางคืนหรี่ลง — เปลี่ยนรูปได้ที่ `brand/mascot.webp` (รูปเต็มตัว พื้นหลังโปร่งใส ตัดขอบชิดตัว)

เปิดใช้: **`https://<โดเมนบอต>/sign/`** (เสิร์ฟจากเซิร์ฟเวอร์บอตตัวเดิม ไม่ต้องตั้งค่าเพิ่ม)
แล้วกดปุ่ม **ติดตั้งโปรแกรม** มุมขวาบน จะได้ไอคอนบนคอม/มือถือ เปิดได้แม้ไม่มีเน็ต

## ใช้งาน 4 ขั้น

| ขั้น | ทำอะไร |
| --- | --- |
| 1 งานออกแบบ | ใส่ไฟล์ JPG/PNG (ลากมาวาง หรือ Ctrl+V ก็ได้) — ป้ายติดผนังจะปรับความสูงตามสัดส่วนรูปให้เอง · ยังไม่มีงาน → พิมพ์ข้อความ เลือกชุดสี |
| 2 ชนิดและขนาด | ไวนิลตาไก่ · ไวนิลขึงโครง · โฟมบอร์ด · สติ๊กเกอร์ · **สติ๊กเกอร์ติดกระจก/ฟิล์มฝ้า** (พิมพ์สี / ฟิล์มฝ้าเว้นลาย / ตาข่ายมองทางเดียว One Way) · อะคริลิค · ป้ายกล่องไฟ · **ป้ายตัวอักษรติดผนัง** · **ป้ายไฟนีออน LED** · **ป้ายยื่นสองหน้า** · **ป้ายขาตั้งโครงเหล็ก** · **ป้ายโครงการ CNC** (มีเสา/ไม่มีเสา) · **บิลบอร์ด** · **ฉากแบ็คดรอป** · **ธงญี่ปุ่น** · **สแตนดี้ไดคัท** (ตั้งพื้น ฐานตรง ขาค้ำหลัง) · โรลอัพ · X-Stand · **บัตร/บัตรสมนาคุณ** (รันนัมเบอร์) · **โปสเตอร์/ใบปลิว** · **ป้ายตั้งโต๊ะ/เมนู** · **ชนิดงานของร้าน** — กรอกกว้าง × สูงเป็นซม. หรือกดขนาดสำเร็จรูป (A3–A0, 80×200 ฯลฯ) · **รูปทรงชิ้นงาน** (สติ๊กเกอร์ โฟม อะคริลิค บัตร สแตนดี้ ติดกระจก): สี่เหลี่ยม / **มุมมน** (% ความมน) / **วงกลม-วงรี** / **ไดคัทตามรูป + ขอบขาว** (ซม.) — ไฟล์ PNG พื้นใสตัดตามรูปเป๊ะ ไฟล์มีพื้นตัดตามลาย/ตัวอักษร เก็บสีพื้นรอบลายไว้ |
| 3 ฉาก | ฉากใหม่: **หน้าร้านกระจก** (บานกระจกกรอบอะลูมิเนียม เห็นในร้านลาง ๆ — สติ๊กเกอร์ติดกระจก/ฟิล์มฝ้า) · **ริมถนน** (บิลบอร์ด ธง ป้ายตั้งพื้น) · **ห้องจัดงาน** (แบ็คดรอป บูธ) · **บนโต๊ะ/เคาน์เตอร์** (ป้ายตั้งโต๊ะ เมนู) — งานบัตร: **บนกระดาษ** (สีกระดาษ ขาว/คราฟท์/ดำ/ชมพู/มิ้นท์ มีบัตรซ้อน+เงานุ่ม) · **มือถือบัตร** (มือวาดแบบภาพเหมือน แขนเสื้อร้าน จับบัตร นิ้วโป้งทับหน้าบัตร มีเงานิ้วบนบัตร) · **มือจับ (รูปถ่ายจริง)** มีรูปมาตรฐานสองมือจับบัตรให้ใช้ทันที (ตำแหน่งบัตรวัดไว้แล้ว มุมบัตรโค้งตามรูป) หรือร้านใส่รูปมือจับบัตรเปล่าของตัวเองครั้งเดียว (เก็บในเครื่อง ใช้ได้ทุกงาน · ลบแล้วกลับไปใช้รูปมาตรฐาน · รูปพื้นใสวางบนพื้นขาวให้) ระบบ**หาบัตรขาวในรูปให้เอง** 1–2 ใบ วางงานพร้อมเงาตามรูปจริง นิ้วที่ทับบัตรอยู่ด้านหน้า ไม่ยืดงาน (สัดส่วนต่างเติมสีพื้นงาน) — ดู **สองมือ (รวม) / มือซ้าย / มือขวา** · ปรับมุมบัตร (ลากจุดส้ม) · หมุนงาน 90° · **บันทึกครบ 3 ภาพ** ทีเดียว — ป้าย: พื้นเรียบ · ผนังปูน · ผนังอิฐ · หน้าร้านตึกแถว · รั้วกลางแจ้ง · **ประตูห้องเรียน** · **ประตูห้อง** (ห้องทำงาน/ประชุม) · **ในห้องเรียน** · **รูปหน้าร้านลูกค้า** (ลากจุดส้ม 4 มุม · **คนยืนเทียบ 170 ซม.** ย่อ/ขยายตามขนาดป้ายจริงบนรูป ลากตัวคนไปวางให้เท้าแตะพื้นได้) — ฉากประตู/ห้องเรียนเลือก **ตำแหน่งติดป้าย** ได้: **เต็มบานประตู** (บานขยายตามป้าย มือจับ+กลอนยึดทับป้าย) · บนประตู · เหนือประตู/กระดาน · ข้างประตู/กระดาน (อัตโนมัติ: ป้ายขนาดประตู 55–110 × 150–230 ซม. ติดเต็มบาน ป้ายเล็กติดบนบาน) · ประตูห้องเรียน **เปิดพับชิดผนัง** (เห็นห้องเรียนข้างใน) หรือปิด · **สีผนัง** ชมพู-ฟ้า / ครีม-เขียว / ครีม-น้ำตาล / ขาว-เทา · เปิด/ปิดคนยืนเทียบ 170 ซม. และเส้นบอกขนาด |
| 4 ราคาและส่งออก | ราคาต่อ ตร.ม. (ป้ายแผ่น) หรือต่อชุด (ขาตั้ง) × จำนวน → ยอดรวม · **ค่าใช้จ่ายเพิ่ม** (ค่าออกแบบ/ติดตั้ง/ขนส่ง/รายการอื่น สูงสุด 8 รายการ) · **ส่วนลด** · **VAT 7%** · **มัดจำ** 30%/50%/ชำระเต็ม · **นัดรับงาน** · หมายเหตุถึงลูกค้า/ถึงช่าง · ชื่อลูกค้า ชื่อร้าน เบอร์ โลโก้ ลงแถบใต้ภาพ · กด **บันทึกรูปส่งลูกค้า** · **ทำใบเสนอราคา PDF** · **บันทึกงานนี้ไว้ในเครื่อง** |

## แถบเครื่องมือด้านบน

| ปุ่ม | ทำอะไร |
| --- | --- |
| ↶ ↷ | ย้อนกลับ / ทำซ้ำ (**Ctrl+Z**, **Ctrl+Y** หรือ Ctrl+Shift+Z) — ย้อนได้ทุกอย่าง: ชนิด ขนาด ฉาก ข้อความ ไฟล์งาน มุมป้ายบนรูปลูกค้า |
| งานของฉัน | บันทึกงานพร้อมชื่อ (**Ctrl+S**) เก็บไฟล์งาน รูปหน้าร้าน และภาพย่อไว้ในเครื่อง · ค้นหาตามชื่องาน/ลูกค้า/ชนิดป้าย · เปิดงานเก่ามาแก้ต่อ · ลบ (กด 2 ครั้ง) |
| ตัวเลือกของร้าน | **ชุดสีของร้าน** (เลือกสีพื้น/ข้อความ/ป้ายเบอร์เอง) · **สีผนังของร้าน** · **ฟอนต์ของร้าน** (อัปโหลด .ttf .otf .woff) · **ชนิดงานของร้าน** (เพิ่มเอง) · ขนาดประจำร้าน · เลือกชนิดป้าย/ฉากที่โชว์ · **ส่งออก/นำเข้าไฟล์ตัวเลือก** ย้ายไปเครื่องอื่น (รวมชื่อร้าน โลโก้ ราคา) |
| ⇆ แผง | ย้ายแผงตั้งค่าไปซ้าย/ขวา (คอมพิวเตอร์) |
| ☾ / ☀ | โหมดมืด / สว่าง (จำไว้ในเครื่อง ไม่เลือก = ตามระบบ) |
| v4.11.0 | รุ่นของโปรแกรม — **อัปเดตเองอัตโนมัติ** |

- ขั้น 1 พิมพ์ข้อความ: กด **+ ชุดสีใหม่** สร้างชุดสีเอง · เลือก **ฟอนต์** ข้อความหลัก/รอง (ฟอนต์ไทย Google 18 แบบ หรือฟอนต์ที่ร้านอัปโหลด)
- ขั้น 2: **+ บันทึกขนาดนี้** เก็บเป็นขนาดประจำร้าน (กด × ลบ) · **สีโครงเหล็ก/สีเสา** ดำ เทา ขาว สแตนเลส น้ำตาล หรือเลือกสีเอง (ขาตั้งโครงเหล็ก / ป้าย CNC)
- ขั้น 3 ฉากประตู/ห้องเรียน: กด **+ สีผนังใหม่** เลือกสีผนังบน/ล่างเอง
- ตัวเลือกของร้านเก็บในเครื่อง (ฟอนต์เก็บใน IndexedDB) — ไฟล์ที่นำเข้าถูกตรวจทุกช่อง สีรับเฉพาะ #rrggbb
- ค้นหาชนิดป้าย (ขั้น 2) และฉาก (ขั้น 3) ได้ เช่น "สติ" "ประตู" "กล่องไฟ"
- **กล่องขนาดมุมภาพ** (คอมพิวเตอร์): กว้าง (X) · สูง (Y) · หนา (Z) ของชนิดนั้น · พื้นที่ ตร.ม.
- งานที่ทำอยู่ **บันทึกเองตลอด** (รวมไฟล์งานและรูปหน้าร้าน) ปิดแอปแล้วเปิดใหม่ งานยังอยู่ครบ

## ส่งออก 9 แบบ + ลิงก์ 3 มิติ

| แบบ | ใช้ทำอะไร |
| --- | --- |
| รูป JPG | ส่งเข้า LINE เร็ว ไฟล์เล็ก |
| รูป PNG | คมที่สุด ไม่มีรอยบีบอัด เหมาะกับตัวหนังสือเล็ก |
| ใบเสนอราคา PDF | A4: หัวร้าน+โลโก้ · ลูกค้า · เลขที่ (Q+ปี พ.ศ.เดือนวัน-เวลา) · วันที่ · ภาพจำลอง · **ตารางหลายรายการ** (ป้าย + ค่าใช้จ่ายเพิ่ม) · รวมเป็นเงิน · ส่วนลด · ภาษีมูลค่าเพิ่ม 7% · **รวมทั้งสิ้น + ตัวหนังสือ** (มีสตางค์) · มัดจำ/คงค้างวันรับงาน · นัดรับงาน · หมายเหตุ · ช่องเซ็นชื่อ |
| ไฟล์ 3 มิติ (.glb) | โมเดล 3 มิติ หมุนดูได้ใน 3D Viewer ของ Windows / แอปดูไฟล์ 3 มิติ / ส่งให้ทีมออกแบบ · เลือกได้ **ป้าย + ฉาก** (ค่าเริ่มต้น: ฉากที่เปิดอยู่ เช่น หน้าร้านตึกแถว ห้องเรียน + คนยืนเทียบ · ฉากรูปหน้าร้านลูกค้า = ป้าย + รูปหน้างาน) หรือ **เฉพาะป้าย** — จำตัวเลือกไว้ในเครื่อง ใช้กับ HTML พรีวิว และลิงก์ดู 3 มิติด้วย |
| **ใบสั่งผลิต (ส่งช่าง)** | PDF A4 ภายในร้าน: เลขที่งาน J… · วันสั่ง/วันนัดรับ · ลูกค้า · ภาพงาน · สเปก (ชนิด ขนาด จำนวน วัสดุ) · **งานตกแต่ง** (จำนวนตาไก่ / รายการเหล็ก / เลขรัน+ต้นขั้ว / วัสดุ+ไฟตัวอักษร ฯลฯ) · ไฟล์งาน + **ความละเอียดตอนพิมพ์จริง (dpi)** เตือนถ้าไฟล์เล็กไป/สัดส่วนไม่ตรง · หมายเหตุถึงช่าง · ช่องติ๊กขั้นตอน ตรวจไฟล์ → พิมพ์/ตัด → เคลือบ/ประกอบ → QC → ส่งมอบ/ติดตั้ง |
| **เทียบ 2 แบบ** | ขั้น 4 กด **เก็บภาพนี้เป็นแบบที่ 1** → ปรับสี/ชนิด/ขนาด/ฉาก → **เก็บเป็นแบบที่ 2** → **ทำหน้าเทียบ 2 แบบ**: หน้า A4 แบบละครึ่งหน้า (ป้ายเลข 1/2 · ชนิด ขนาด ราคา ฉาก ชุดสี) + ช่องให้ลูกค้าติ๊กเลือก — รูป JPG ส่ง LINE หรือ PDF · ภาพที่เก็บไว้อยู่ในเครื่อง ปิดแอปแล้วยังอยู่ |
| **HTML พรีวิว 3 มิติ** | ไฟล์ .html ไฟล์เดียว (~1 MB) ฝังโมเดล + ตัวดู 3 มิติ + รูปตัวอย่าง + โลโก้ร้าน — ส่งทาง LINE/อีเมล/แฟลชไดรฟ์ ลูกค้าแตะ/ดับเบิลคลิกเปิดในเบราว์เซอร์ หมุนดูได้ **ไม่ต้องลงแอป ไม่ต้องต่อเน็ต** · มีปุ่มโทรสั่งทำ หมุนอัตโนมัติ มุมเริ่มต้น เต็มจอ **บันทึกรูปมุมนี้ (PNG)** · เครื่องที่เปิด 3 มิติไม่ได้ โชว์รูปตัวอย่างแทน · ฉากรูปหน้าร้านลูกค้า = 3 มิติบนรูปหน้างาน |

**ป้าย + ฉาก (ฉาก 3 มิติ):** ไฟล์/HTML/ลิงก์ ใส่ฉากที่เปิดอยู่ไปด้วย (ผนัง ตึกแถว ประตูม้วน ห้องเรียน ฯลฯ) ไฟล์ราว 1–2 MB (เฉพาะป้าย ~0.2 MB)
- ลูกค้าเปิดมา **มุมเดียวกับที่ร้านเลือกในแอป** (หน้าตรง/มุมเฉียง/…) ส่ายกล้องโชว์ ลากหมุนดูรอบ ๆ ได้ · คนยืนเทียบหันหากล้องเสมอ
- **ซูมดูป้าย** เข้าหน้าป้ายตรง ๆ (ป้ายยื่นแขวนสองหน้า: เข้าด้านที่หันหากล้อง)

**3 มิติบนรูปหน้างาน (ฉากรูปหน้าร้านลูกค้า):** ไฟล์ .glb / HTML พรีวิว / ลิงก์ดู 3 มิติ ใส่รูปถ่ายหน้างานไปด้วย
- แอปหามุมกล้องตอนถ่ายจาก 4 มุมป้ายที่ลากไว้ + ขนาดป้ายจริง (ป้ายเล็กในรูป/ลากไม่เป๊ะ ใช้มุมกล้องมือถือปกติ ~66°) แล้ววางรูปบนผนังระนาบเดียวกับป้าย
- ฉากหลังเป็น **กล่อง 3 มิติ**: ผนัง (ระนาบเดียวกับป้าย) + พื้นแนวนอนหน้าผนัง (ระดับพื้น = เท้าคนยืนเทียบ หรือประมาณจากป้าย) หมุนดูแล้วพื้นราบไปกับพื้น ไม่ใช่แผ่นรูปแบน
- ลูกค้าเปิดมา **เห็นเหมือนรูปหน้างาน** (ป้ายตรงตำแหน่งเดิม รูปไม่เอียง) · ส่ายกล้องเบา ๆ ให้เห็นว่าเป็น 3 มิติ · ลากขยับมุมได้ ซ้าย-ขวา ±23° ขึ้น-ลง ±13°
- **ซูมดูป้าย** (ปุ่ม หรือแตะสองครั้ง) กล้องเข้าไปใกล้ป้าย เห็นงานคมชัด (ป้ายเป็นโมเดลจริง คมกว่ารูปถ่าย) · กดอีกทีกลับไปดูทั้งภาพ · ถ่างนิ้วซูมเองได้
- คนยืนเทียบ 170 ซม. อยู่ตรงตำแหน่งเดียวกับภาพ 2 มิติ ระยะเท่าป้าย · ไฟล์ราว 0.5–1 MB (รูปย่อด้านยาวไม่เกิน 2048 px)
- ปุ่ม **ซูมดูป้าย** มีในลิงก์ 3 มิติทุกแบบ (ฉากอื่น: เข้าไปดูหน้าป้ายตรง ๆ)

**ตัวดู 3 มิติ (ลิงก์/HTML) แบบโปรแกรม 3D:** **ลูกศรโค้งวนรอบป้าย** (เส้นบาง สีจาง ๆ ขนาดตามชิ้นงาน — บัตรเล็กก็ลูกศรเล็ก · วงรีใต้/รอบป้าย หัวลูกศรชี้ทางหมุน — แตะลูกศรซ้าย/ขวาหมุนไปทางนั้น ~35° · ซูมเข้าใกล้แล้วจางหาย) · ไฟล์เฉพาะป้าย: **พื้นตาราง + เส้นแกน X (กว้าง) Y (สูง) Z (หนา)** สีเดียวกับกล่องขนาดในแอป · หน้าเว็บไม่ซูมทั้งหน้าตอนถ่างนิ้ว (ปุ่มไม่หลุดขอบ) · ชื่อร้านยาวขึ้นบรรทัดใหม่ ปุ่มโทรสั่งทำอยู่ในจอเสมอ · ปุ่มกลมไอคอนลูกศรโค้ง ↺ ↻ หมุน · มุมสูง/ต่ำ · แว่นขยาย ซูม (กดค้างได้ · คอมใช้ปุ่มลูกศรบนคีย์บอร์ด + −) · เปิดมาใกล้ขึ้น: รูปหน้างานบนมือถือแนวตั้งเริ่มซูมเข้า · ฉากเริ่มที่ป้าย + คนพอดีจอ

**ลิงก์ดู 3 มิติ (ส่งลูกค้า):**
- ลูกค้าแตะลิงก์ เปิดในเบราว์เซอร์มือถือได้เลย **ไม่ต้องลงแอป** — ป้ายหมุนโชว์เอง ลากนิ้วหมุนดูรอบ ถ่างนิ้วซูม · ปุ่มมุมเริ่มต้น / เต็มจอ / ดาวน์โหลดไฟล์ .glb
- หัวหน้าเป็นชื่อร้าน + ปุ่ม **โทรสั่งทำ** (ใช้เบอร์ในขั้น 4) · ใต้ภาพมีชื่องาน ขนาด ชื่อลูกค้า · แปะลิงก์ใน LINE/Facebook ขึ้นรูปตัวอย่าง
- ลิงก์ใช้ได้ **1 ปี** · ไฟล์เก็บใน Supabase Storage bucket ส่วนตัว `sign-share` (เซิร์ฟเวอร์สร้างให้เองครั้งแรก หรือรัน `supabase/migrations/023_sign_share_bucket.sql`)
- เซิร์ฟเวอร์ตรวจไฟล์ก่อนเก็บ (ต้องเป็น GLB/JPEG จริง ≤ 20 MB) ข้อความถูกล้างแท็ก · สร้างลิงก์ได้ 30 ครั้ง/ชม. ต่อเครื่อง
- เซิร์ฟเวอร์ร้านหลับ (ไม่ได้ใช้นาน) หรือกำลังอัปเดตรุ่น → แอปปลุกเอง (`/sign/api/ping` ทุก 3 วิ สูงสุด 90 วิ) แล้วส่งไฟล์ใหม่ให้อัตโนมัติ
- **คนเปิดดู + ลูกค้าที่สนใจ:** งานของฉัน › **ลิงก์ 3 มิติที่ส่งไป** (หรือปุ่มใต้ลิงก์) — แต่ละลิงก์บอกเปิดกี่ครั้ง กี่คน มาจาก Facebook / LINE / ที่อื่น มือถือ/คอม ล่าสุดเมื่อไหร่ (ไม่รู้ชื่อคนเปิด — Facebook ไม่ให้ข้อมูลนี้) · หน้า 3 มิติมีปุ่ม **สนใจ / ขอราคา** ลูกค้ากรอกชื่อ + เบอร์ (+ ข้อความ) → ขึ้นรายชื่อพร้อมปุ่มโทร และบอทแจ้งเข้า LINE ร้าน (`SIGN_NOTIFY_LINE_IDS` หรือคนใน `ALLOWED_LINE_USER_IDS`) · เปิดแอปแล้วมีลูกค้าใหม่จะเด้งบอก
- ดูยอด/รายชื่อได้เฉพาะเครื่องที่สร้างลิงก์ (เซิร์ฟเวอร์ให้กุญแจเจ้าของเก็บในเครื่อง เก็บแค่ค่าแฮช) · เครื่องร้านเปิดลิงก์ตัวเองไม่นับ · บอตพรีวิวลิงก์ของ Facebook/LINE ไม่นับ (นับจากสคริปต์ในหน้า) · คนเดิมรีเฟรชใน 1 นาทีนับครั้งเดียว · ฟอร์มสนใจจำกัด 5 ครั้ง/ชม. ต่อเครื่อง
- ต้องมีเน็ต (ส่งไฟล์ขึ้นเซิร์ฟเวอร์ร้าน) · เปิดแอปจากไฟล์ในเครื่องหรือโฮสต์อื่นที่ไม่มีเซิร์ฟเวอร์บอต จะสร้างลิงก์ไม่ได้ ใช้ไฟล์ .glb แทน

## อัปเดตอัตโนมัติ (แอปที่ติดตั้งไว้)

- ไฟล์แอปขอจากเซิร์ฟเวอร์ก่อนทุกครั้ง (เน็ตหลุดค่อยใช้ของในเครื่อง) เปิดแอปเมื่อไหร่ได้รุ่นล่าสุดเสมอ
- **อัปเดตเรียลไทม์:** แอปที่เปิดอยู่ต่อสายสดกับเซิร์ฟเวอร์ร้าน (`/sign/api/live`) — ขึ้นรุ่นใหม่เมื่อไหร่ ทุกเครื่องที่เปิดแอปอยู่รู้ภายในไม่กี่วินาที
  ขึ้น "มีรุ่นใหม่ vX กำลังอัปเดต…" แล้วอัปเดตเอง ไม่ต้องปิดเปิดแอป · ป้ายรุ่นมุมบนมี **จุดเขียว** = ต่อสายอยู่ · แตะป้ายรุ่นดูรุ่น + **เวลาที่ขึ้นระบบ**
  (จอมือถือแคบมากเหลือแค่จุด · ยังไม่ได้ติดตั้งแอปบนมือถือ ป้ายรุ่นหลบให้ปุ่มติดตั้ง) · พับแอป/สลับแอปปิดสายให้ประหยัดแบต กลับมาต่อใหม่เอง
- สำรอง: เช็กรุ่นใหม่ทุก 10 นาที และทุกครั้งที่สลับกลับมาที่แอป เจอรุ่นใหม่ → เก็บงานที่ทำอยู่ → โหลดรุ่นใหม่เอง
  (รอจนไม่ได้พิมพ์อยู่/ไม่ได้เปิดหน้าต่างค้าง) แล้วขึ้นข้อความ "อัปเดตเป็นรุ่นใหม่แล้ว งานเดิมอยู่ครบ"
- **ปล่อยรุ่นใหม่:** เลื่อน `APP_VERSION` ใน `app.js` และ `VERSION` ใน `sw.js` ให้ตรงกัน (มีเทสต์เช็ก) แล้ว merge เข้า main — Render deploy ให้เอง

**แถบเหนือภาพ (3 มิติ):** หน้าตรง · มุมเฉียง · มุมคนมอง (กล้องสูง 1.6 ม. แหงนดูป้าย) · ด้านข้าง (เห็นความหนา/หมุด/ขาตั้ง) · ใกล้ป้าย (ป้ายชื่อห้องเล็ก ๆ เห็นงานชัด)
· **หมุนโชว์** ส่ายกล้องให้ลูกค้าดูเอง · **กลางคืน** กล่องไฟเปิดไฟ ป้ายอื่นมีสปอตไลท์ส่อง
— ลากเมาส์/นิ้วเพื่อหมุน เลื่อนล้อหรือถ่างนิ้วเพื่อซูม · รูปที่บันทึกใช้มุมกล้องที่เห็นอยู่

- **ป้ายขาตั้งโครงเหล็ก + รายการตัดเหล็ก** (ขั้น 2 — ใช้กับ "ไวนิลขึงโครง" ได้ด้วย คิดเฉพาะกรอบ):
  ตั้งความสูงรวม · ฐานลึก · เหล็กกล่อง ¾–2 นิ้ว · ความหนา · คร่าวนอน/คร่าวตั้ง (เว้นว่าง = อัตโนมัติ: คร่าวนอนห่าง ≤ 60 ซม. คร่าวตั้งห่าง ≤ 100 ซม.)
  · ฐานสี่เหลี่ยม / ขาตัว T · **ตัดตรงชน / เข้ามุม 45°** → ผังโครง · ช่องโครงใหญ่สุด · **ความยาวเหล็กรวม · จำนวนชิ้น · ตารางชิ้นส่วน (ยาว/ชิ้น + มุมตัด)**
  · **แผนตัดจากเหล็กเส้นยาว 6 ม.** (ใช้กี่เส้น เศษเท่าไร เผื่อคมเลื่อย 3 มม.) · น้ำหนักโดยประมาณ · ค่าเหล็ก (ใส่ราคาเส้นละ)
  · **ดาวน์โหลดรายการตัด TXT หน่วย มม.** / คัดลอกส่ง LINE · ภาพ 3 มิติ "โชว์เฉพาะโครงเหล็ก" มีเส้นบอกสูงรวม/ฐานลึก
  — ตัวอย่าง 80×120 สูงรวม 150 ฐานลึก 60 เหล็ก 1 นิ้ว เข้ามุม 45° = 9 ชิ้น 805 ซม. เหล็ก 2 เส้น ~7.2 กก. (ค่าเบื้องต้นสำหรับจัดแบบ ต้องตรวจวัสดุ แรงลม จุดยึดก่อนผลิต)
- **ป้ายโครงการ CNC:** แผ่นอะลูมิเนียมคอมโพสิตบนโครงเหล็กหนา 5 ซม. ขั้น 2 เลือก **เสา**: **มีเสา ตั้งพื้น** (เสาเหล็กกล่องคู่ 10×10 ซม. บนฐานปูน ขอบล่างแผ่นสูงจากพื้น 80 ซม.) หรือ **ไม่มีเสา ติดผนัง** (ยึดผนัง/รั้ว/หน้าอาคาร ลอยจากผนัง 1 ซม. สูงตามฉาก — ไม่ต้องเลือกสีเสา)
  — ตัวอักษร/โลโก้ (ส่วนที่สีต่างจากพื้นงานชัด ๆ) กลายเป็น **ตัวนูนตัด CNC หนา 1.5 ซม.** มีเงาตกบนแผ่น หมุนเฉียงเห็นความหนา
  แผ่นเป็นสีพื้นของงาน → เหมาะกับงานตัวอักษร/โลโก้บนพื้นสีเรียบ · ราคาคิดต่อป้าย (รวมเสา / ติดผนัง)
- **บัตร / บัตรสมนาคุณ (รันนัมเบอร์):** ขนาดสำเร็จ บัตรสมนาคุณ 18×7 · คูปอง+ต้นขั้ว 20×8 · นามบัตร 9×5.5 · บัตรสมาชิก 8.6×5.4 · บัตรเชิญ 10×15 · บัตรคิว 7×10 — ราคาคิด **ต่อใบ**
  ขั้น 2 ช่อง **รันนัมเบอร์**: คำนำหน้า (No. / เลขที่ / A-) · เริ่มที่เลข · จำนวนหลัก (0001) · ตำแหน่ง ซ้าย/ขวา บน/ล่าง · ขนาด 9/12/16 pt · สีเลข
  · **ต้นขั้ว** (กว้างกี่ ซม. ฝั่งซ้าย) มีเส้นปรุ + เลขเดียวกันบนต้นขั้ว + ช่องเขียน ชื่อ/โทร/วันที่ (งานพิมพ์ข้อความจัดให้อยู่ฝั่งขวาของเส้นปรุเอง)
  · จำนวนใบ (ขั้น 4) = จำนวนเลข เช่น 100 ใบ เริ่ม 1 → No.0001 – No.0100 · ภาพจำลองโชว์ใบแรก · แถบใต้ภาพ/ใบเสนอราคาบอกช่วงเลข
  · ส่งออก **ไฟล์พิมพ์ (จัดหน้า)**: เลือกกระดาษ → บอกกี่ใบ/แผ่น ใช้กี่แผ่น (หมุนบัตรให้เองถ้าได้มากกว่า) · รูปบัตร 300 dpi ฝังครั้งเดียว ตัวเลขเป็นตัวอักษรเวกเตอร์คมทุกขนาด (Helvetica ตัวหนา)
  — ตัวอย่าง 18×7 ซม. 100 ใบ: A4 ได้ 3 ใบ/แผ่น = 34 แผ่น · A3 ได้ 6 ใบ/แผ่น (หมุน) = 17 แผ่น
- **ป้ายตัวอักษรติดผนัง:** ตัวอักษรหนา 3 ซม. ลอยจากผนัง 2.5 ซม. (ส่วนที่สีต่างจากพื้นงาน = ตัวอักษร ไม่มีแผ่นพื้น) · วัสดุ: **สีตามงาน / สแตนเลส / ทอง / ดำ / ขาว** · ไฟ: **ไม่มี / ไฟส่องหลัง (แสงฟุ้งบนผนัง) / ไฟหน้า** — กดปุ่ม "กลางคืน" ดูไฟ
- **ป้ายไฟนีออน LED:** หลอดนีออนตามขอบตัวอักษรบนอะคริลิคใสลอยจากผนัง · สีไฟ **ตามงาน / ขาววอร์ม / ชมพู / ฟ้า / เหลือง / เขียว / แดง / สีอื่น** · กลางคืนเรืองแสงส่องผนัง (เริ่มที่ฉากผนังอิฐ)
- **ป้ายยื่นสองหน้า:** กล่องหนา 12 ซม. ตั้งฉากกับผนัง พิมพ์สองหน้า แขวนใต้แขนเหล็ก · เปิด/ปิด **กล่องไฟ** · เลือกชนิดนี้แล้วกล้องหมุนไปมุมด้านข้างให้เห็นหน้าป้าย
- **ธงญี่ปุ่น:** ผืนธงพลิ้ว เสาข้าง ราวบน ฐานถ่วงน้ำ · **ฉากแบ็คดรอป:** ไวนิลบนโครงทรัส 30 ซม. ยางยืดยึด ราคาต่อ ตร.ม. · **บิลบอร์ด:** เสาเดี่ยว ฐานปูน ทางเดินซ่อมบำรุงมีราว **ไฟส่อง** (เปิด/ปิดได้) สูงจากพื้น ≥ 4 ม.
- **โปสเตอร์/ใบปลิว:** A5–A2, DL ราคาต่อแผ่น ใช้ฉากบัตร (บนกระดาษ/มือถือ) ส่งออกไฟล์พิมพ์จัดหน้าได้ · **ป้ายตั้งโต๊ะ/เมนู:** อะคริลิคใสพับ L เอน 10° ตั้งบนโต๊ะไม้
- เปลี่ยนชนิดแล้วฉากเปลี่ยนให้เหมาะเอง (แบ็คดรอป → ห้องจัดงาน · บิลบอร์ด/ธง → ริมถนน · นีออน → ผนังอิฐ) และถ้าขนาดเดิมห่างจากขนาดปกติของชนิดใหม่มาก ใช้ขนาดมาตรฐานของชนิดนั้น
- งานบัตรเลือกชนิดแล้ว ฉากเปลี่ยนเป็น **บนกระดาษ** เอง (รายการฉากโชว์เฉพาะที่เหมาะกับบัตร: บนกระดาษ · มือถือบัตร · พื้นเรียบ · ผนัง) ไม่มีคนยืนเทียบ
- **ชนิดงานของร้าน** (ตัวเลือกของร้าน → + เพิ่มชนิดงาน): ตั้งชื่อเอง (เช่น ป้ายพลาสวูด บัตรคิว ป้ายตั้งโต๊ะ) · หน้าตาภาพจำลองเหมือนชนิดไหน (ไวนิล โฟมบอร์ด อะคริลิค กล่องไฟ บัตร โรลอัพ ฯลฯ)
  · คิดราคา ต่อ ตร.ม. / ต่อชิ้น / ต่อชุด · หน่วยเรียก · ขนาดที่ใช้บ่อย (พิมพ์ 60x90, 120x240) · คำอธิบาย — โผล่ท้ายรายการขั้น 2 มีป้าย "ของร้าน" แก้/ลบได้ ย้ายเครื่องไปกับไฟล์ตัวเลือก
- สีหน้าป้ายในภาพ 3 มิติปรับแสงให้ใกล้สีงานพิมพ์จริง (มุมหน้าตรง วัดได้ 43,58,104 เทียบงาน 44,59,105)
- เครื่องที่เปิด 3 มิติไม่ได้ จะใช้ภาพ 2 มิติแทนอัตโนมัติ · ฉาก "รูปหน้าร้านลูกค้า" เป็นภาพ 2 มิติลาก 4 มุม
- ราคาไม่ใส่ = ไม่โชว์ราคาบนภาพ · ป้ายแผ่นคิด พื้นที่ × ราคาต่อ ตร.ม. แล้ว **ปัดเศษขึ้นเป็นบาท** ต่อชิ้น
- ราคาต่อ ตร.ม. แยกจำไว้ทีละชนิดป้าย ชื่อร้าน/เบอร์/โลโก้ก็จำไว้ในเครื่อง · ไฟล์งานกับรูปลูกค้าเก็บใน IndexedDB ของเครื่องนั้น (ไม่ส่งขึ้นเซิร์ฟเวอร์)
- มือถือ: ในหน้าต่างบันทึกรูป กด **แชร์** ส่งเข้า LINE ได้เลย หรือกดค้างที่รูปแล้วบันทึก

## เพิ่มฉากใหม่
