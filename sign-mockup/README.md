# นัดพอน Sign Mockup — จำลองป้ายให้ลูกค้าเห็นก่อนสั่งผลิต

เว็บแอปสำหรับหน้าร้าน: ใส่ไฟล์งาน (หรือพิมพ์ข้อความเร็ว ๆ) เลือกชนิดป้ายกับขนาด
แล้วได้ **ภาพ 3 มิติ** ของป้ายจริงติดอยู่บนผนัง หน้าร้าน หรือรั้ว — ลากหมุนดูรอบ ๆ ซูมเข้าออกได้
มีเส้นบอกขนาด คนยืนเทียบ ราคา และโหมดกลางคืน บันทึกเป็นรูป JPG ส่งลูกค้าทาง LINE ได้ทันที

เปิดใช้: **`https://<โดเมนบอต>/sign/`** (เสิร์ฟจากเซิร์ฟเวอร์บอตตัวเดิม ไม่ต้องตั้งค่าเพิ่ม)
แล้วกดปุ่ม **ติดตั้งโปรแกรม** มุมขวาบน จะได้ไอคอนบนคอม/มือถือ เปิดได้แม้ไม่มีเน็ต

## ใช้งาน 4 ขั้น

| ขั้น | ทำอะไร |
| --- | --- |
| 1 งานออกแบบ | ใส่ไฟล์ JPG/PNG (ลากมาวาง หรือ Ctrl+V ก็ได้) — ป้ายติดผนังจะปรับความสูงตามสัดส่วนรูปให้เอง · ยังไม่มีงาน → พิมพ์ข้อความ เลือกชุดสี |
| 2 ชนิดและขนาด | ไวนิลตาไก่ · ไวนิลขึงโครง · โฟมบอร์ด · สติ๊กเกอร์ · อะคริลิค · ป้ายกล่องไฟ · โรลอัพ · X-Stand — กรอกกว้าง × สูงเป็นซม. หรือกดขนาดสำเร็จรูป (A3–A0, 80×200 ฯลฯ) |
| 3 ฉาก | พื้นเรียบ · ผนังปูน · ผนังอิฐ · หน้าร้านตึกแถว · รั้วกลางแจ้ง · **ประตูห้องเรียน** · **ประตูห้อง** (ห้องทำงาน/ประชุม) · **ในห้องเรียน** · **รูปหน้าร้านลูกค้า** (ลากจุดส้ม 4 มุม) — ฉากประตู/ห้องเรียนเลือก **ตำแหน่งติดป้าย** ได้: **เต็มบานประตู** (บานขยายตามป้าย มือจับ+กลอนยึดทับป้าย) · บนประตู · เหนือประตู/กระดาน · ข้างประตู/กระดาน (อัตโนมัติ: ป้ายขนาดประตู 55–110 × 150–230 ซม. ติดเต็มบาน ป้ายเล็กติดบนบาน) · ประตูห้องเรียน **เปิดพับชิดผนัง** (เห็นห้องเรียนข้างใน) หรือปิด · **สีผนัง** ชมพู-ฟ้า / ครีม-เขียว / ครีม-น้ำตาล / ขาว-เทา · เปิด/ปิดคนยืนเทียบ 170 ซม. และเส้นบอกขนาด |
| 4 ราคาและส่งออก | ราคาต่อ ตร.ม. (ป้ายแผ่น) หรือต่อชุด (ขาตั้ง) × จำนวน → ยอดรวม · ชื่อลูกค้า ชื่อร้าน เบอร์ โลโก้ ลงแถบใต้ภาพ · กด **บันทึกรูปส่งลูกค้า** |

**แถบเหนือภาพ (3 มิติ):** หน้าตรง · มุมเฉียง · มุมคนมอง (กล้องสูง 1.6 ม. แหงนดูป้าย) · ด้านข้าง (เห็นความหนา/หมุด/ขาตั้ง) · ใกล้ป้าย (ป้ายชื่อห้องเล็ก ๆ เห็นงานชัด)
· **หมุนโชว์** ส่ายกล้องให้ลูกค้าดูเอง · **กลางคืน** กล่องไฟเปิดไฟ ป้ายอื่นมีสปอตไลท์ส่อง
— ลากเมาส์/นิ้วเพื่อหมุน เลื่อนล้อหรือถ่างนิ้วเพื่อซูม · รูปที่บันทึกใช้มุมกล้องที่เห็นอยู่

- สีหน้าป้ายในภาพ 3 มิติปรับแสงให้ใกล้สีงานพิมพ์จริง (มุมหน้าตรง วัดได้ 43,58,104 เทียบงาน 44,59,105)
- เครื่องที่เปิด 3 มิติไม่ได้ จะใช้ภาพ 2 มิติแทนอัตโนมัติ · ฉาก "รูปหน้าร้านลูกค้า" เป็นภาพ 2 มิติลาก 4 มุม
- ราคาไม่ใส่ = ไม่โชว์ราคาบนภาพ · ป้ายแผ่นคิด พื้นที่ × ราคาต่อ ตร.ม. แล้ว **ปัดเศษขึ้นเป็นบาท** ต่อชิ้น
- ราคาต่อ ตร.ม. แยกจำไว้ทีละชนิดป้าย ชื่อร้าน/เบอร์/โลโก้ก็จำไว้ในเครื่อง (ไฟล์งานกับรูปลูกค้าไม่เก็บ)
- มือถือ: ในหน้าต่างบันทึกรูป กด **แชร์** ส่งเข้า LINE ได้เลย หรือกดค้างที่รูปแล้วบันทึก

## ไฟล์

| ไฟล์ | หน้าที่ |
| --- | --- |
| `core.js` | ตรรกะล้วน (ขนาด ราคา ตาไก่ กล้อง โฮโมกราฟี) — เทสต์ที่ `tests/signMockup.test.js` |
| `scene3d.js` | เวที 3 มิติ (three.js): ฉาก 5 แบบ ตัวป้าย 7 ชนิดพร้อมอุปกรณ์จริง คนเทียบ แสงกลางวัน/กลางคืน มุมกล้อง |
| `vendor/` | three.js 0.160 (MIT) เก็บไว้ในโปรเจกต์ ใช้ออฟไลน์ได้ ไม่พึ่ง CDN |
| `render.js` | ภาพ 2 มิติ (รูปหน้าร้านลูกค้า / เครื่องที่ไม่มี 3 มิติ) + หน้าป้าย เส้นบอกขนาด แถบรายละเอียด |
| `app.js`, `index.html`, `app.css` | หน้าจอ 4 ขั้น ปุ่มติดตั้ง ส่งออกรูป |
| `manifest.webmanifest`, `sw.js`, `icons/` | ติดตั้งเป็นแอป + ใช้ออฟไลน์ — แก้ไฟล์แอปแล้วให้เลื่อน `VERSION` ใน `sw.js` |

ไม่ต้อง build อะไร เป็นไฟล์นิ่งล้วน จะเปิดจากที่อื่น (GitHub Pages, Netlify, Vercel) ก็ได้
แค่ต้องเป็น https ปุ่มติดตั้งถึงจะขึ้น · ฟอนต์ Kanit / IBM Plex Sans Thai โหลดจาก Google Fonts

## เพิ่มฉากใหม่

ฉาก 3 มิติอยู่ใน `scene3d.js` (ฟังก์ชัน `build…` แล้วใส่ชื่อใน `BUILD`) ฉาก 2 มิติสำรองอยู่ใน `render.js` (`SCENE_DRAW`)
และชื่อ/คำอธิบาย/ตำแหน่งติดป้ายอยู่ใน `core.js` (`SCENES`, `SCENE_ORDER`) — ฉากไหนมีประตูหรือกระดานให้ใส่ `spots`
แล้วกำหนด `spotX` / `spotZ` / `focus` ในฉาก 3 มิติ (ดู `doorSpots` เป็นตัวอย่าง)
