# รูปแบรนด์น้องหมาม่วงจด (เสิร์ฟที่ https://<โดเมนบอต>/brand/<ไฟล์>)

PNG พื้นหลังโปร่งใส ด้านยาว 512px ทุกไฟล์ บอตหยิบใช้เองอัตโนมัติ (ไม่ต้องตั้ง env)

| ไฟล์ | ท่า | ใช้ที่ |
|---|---|---|
| `mascot.png` | ถือคลิปบอร์ด + ปากกา | การ์ด "บันทึกสำเร็จ" (มุมขวาของแถบหมวด, 72px) |
| `mascot-wave.png` | นั่งโบกมือ ยิ้ม | ข้อความต้อนรับตอนเพิ่มเพื่อน |
| `mascot-clipboard-wave.png` | ยืนถือคลิปบอร์ด โบกมือ | (สำรอง) |
| `mascot-sit.png` | นั่งยกมือ | (สำรอง) |
| `mascot-happy.png` | ยิ้มหลับตา | (สำรอง) |
| `mascot-hello.png` | หมอบ โบกมือ | (สำรอง) |
| `mascot-peek.png` | โผล่หน้า ยิ้ม | (สำรอง — เหมาะทำแบนเนอร์ `BRAND_HERO_IMAGE_URL`) |
| `mascot-pen.png` | ถือปากกา | (สำรอง) |
| `mascot-rest.png` | หมอบมองกล้อง | (สำรอง) |
| `mascot-sleep.png`, `mascot-sleep-2.png` | หลับ | (สำรอง) |

- บอตต้องรู้โดเมนตัวเอง: บน Render ใช้ `RENDER_EXTERNAL_URL` ที่ Render ตั้งให้อยู่แล้ว
  ที่อื่นตั้ง `PUBLIC_BASE_URL=https://<โดเมนบอต>`
- ต้องการใช้รูปจากที่อื่นแทน: ตั้ง `BRAND_MASCOT_IMAGE_URL` ทับได้
- ต้นฉบับที่อัปโหลดมีพื้นหลังตารางหมากรุกฝังมา ตัดออกด้วย rembg (u2net) แล้ว trim + ย่อด้วย sharp
