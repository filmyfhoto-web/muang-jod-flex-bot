# รูปแบรนด์ (เสิร์ฟที่ https://<โดเมนบอต>/brand/<ไฟล์>)

วางไฟล์ PNG พื้นหลังโปร่งใสตามชื่อนี้ แล้วบอตใช้เองอัตโนมัติ (ไม่ต้องตั้ง env)

| ไฟล์ | ท่า | ใช้ที่ |
|---|---|---|
| `mascot.png` | ถือคลิปบอร์ด | การ์ด "บันทึกสำเร็จ" (มุมขวาของแถบหมวด, 72px) |
| `mascot-wave.png` | โบกมือ | ข้อความต้อนรับตอนเพิ่มเพื่อน |
| `mascot-sit.png` | นั่งยกมือ | (สำรอง) |
| `mascot-sleep.png` | หลับ | (สำรอง) |
| `mascot-happy.png` | ยิ้มหลับตา | (สำรอง) |

- ขนาดแนะนำ ≤ 512px ด้านยาว, ไฟล์ ≤ 1 MB (LINE โหลดเร็ว)
- บอตต้องรู้โดเมนตัวเอง: บน Render ใช้ `RENDER_EXTERNAL_URL` ที่ Render ตั้งให้อยู่แล้ว
  ที่อื่นตั้ง `PUBLIC_BASE_URL=https://<โดเมนบอต>`
- ต้องการใช้รูปจากที่อื่น: ตั้ง `BRAND_MASCOT_IMAGE_URL` ทับได้
