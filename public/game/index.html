ข้อจำกัดของโหมดสาธิต (LOCAL DEMO):
• คิวงานเก็บใน “เครื่องนี้” เท่านั้น ยังไม่ซิงก์ข้ามเครื่องพนักงาน — ใช้หลายเครื่องพร้อมกันต้องต่อฐานข้อมูลกลางที่ปลอดภัย (ขั้นถัดไป)
• แผนที่และตัวละครเป็นภาพจำลอง ไม่ใช่ GPS / เวลาจริง และไม่เปลี่ยนสถานะงานเอง
• ยังไม่เชื่อมม่วงจด / LINE OA / NATTA GROUP จนกว่าจะยืนยันให้เชื่อม
