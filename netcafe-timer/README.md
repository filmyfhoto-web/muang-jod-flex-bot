# NetTimer — โปรแกรมจับเวลาใช้อินเทอร์เน็ต (ชำระเงินก่อนใช้งาน)

โปรแกรมเล็ก ๆ (ไฟล์เดียว ~64 KB) สำหรับร้านอินเทอร์เน็ต/ร้านเกม ใช้บนเครื่องแคชเชียร์ที่เป็น Windows
ไม่ต้องติดตั้ง ไม่ต้องใช้ฐานข้อมูล ไม่ต้องต่อเน็ต

## วิธีเปิดใช้งาน

1. คัดลอกโฟลเดอร์ `netcafe-timer` (หรืออย่างน้อยไฟล์ `NetTimer.exe`) ไปไว้ในเครื่อง เช่น `D:\NetTimer\`
2. ดับเบิลคลิก `NetTimer.exe`
3. ข้อมูลทั้งหมดเก็บอยู่ในโฟลเดอร์ `data\` ข้าง ๆ ไฟล์โปรแกรม
   (ถ้าโฟลเดอร์นั้นเขียนไม่ได้ จะเก็บไว้ที่ `%AppData%\NetTimer` แทน)

ใช้ได้กับ Windows 7 / 8 / 10 / 11 (ต้องมี .NET Framework 4 ซึ่งติดมากับ Windows 8 ขึ้นไปอยู่แล้ว
ส่วน Windows 7 ถ้ายังไม่มีให้ติดตั้ง .NET Framework 4.x จาก Microsoft)

### คอมไพล์เองจากซอร์สโค้ด

ดับเบิลคลิก `build.bat` — ใช้ตัวคอมไพเลอร์ C# (`csc.exe`) ที่ติดมากับ Windows อยู่แล้ว
ไม่ต้องติดตั้ง Visual Studio จะได้ไฟล์ `NetTimer.exe` ใหม่ในโฟลเดอร์เดียวกัน

## ขั้นตอนใช้งาน (2 - 3 ขั้นตอนต่อรายการ)

**เริ่มรายการ**

1. เลือกเครื่อง — โปรแกรมเลือก *เครื่องว่างถัดไป* ให้อัตโนมัติ
2. ใส่จำนวนเงินที่ลูกค้าจ่าย (หรือกดปุ่มด่วน 10 / 20 / 30 / 40 / 50 / 100) — โปรแกรมคำนวณนาทีให้เอง
   (หรือจะพิมพ์จำนวนนาที แล้วให้โปรแกรมคิดเงินให้ก็ได้)
3. กด **Enter** เริ่มจับเวลา

**ปิดรายการ** — เลือกแถว → กด **F9** (หรือดับเบิลคลิก) → กด **Enter**

## ความสามารถ

| ความต้องการ | ในโปรแกรม |
|---|---|
| ทำงานกึ่งอัตโนมัติ | นับถอยหลังเอง, คำนวณเงิน ↔ นาทีเอง, เลือกเครื่องว่างให้เอง, เตือนเสียง + กะพริบหน้าต่างเมื่อใกล้หมด/หมดเวลา, คิดค่าใช้เกินเวลาให้เอง |
| แก้ไขรายการจับเวลาได้ | **F4** แก้เครื่อง, รายการใช้งาน, สมาชิก, เวลาเริ่ม, เงินที่จ่าย, เวลาที่ซื้อ, เวลาที่ใช้ไป, หมายเหตุ · **F3** เติมเวลา · **F6** หยุดชั่วคราว/เล่นต่อ · **Del** ยกเลิกรายการ |
| เพิ่ม/แก้ไขรายการใช้งาน | เมนู *ตั้งค่า → รายการใช้งาน และ ราคาต่อชั่วโมง* (เช่น อินเทอร์เน็ต, เล่นเกม, พิมพ์งาน) |
| กำหนดเงินต่อชั่วโมง | ตั้งราคา/ชม. แยกแต่ละรายการใช้งาน ราคาใหม่มีผลกับรายการที่เริ่มหลังจากนั้น |
| เพิ่มผู้ใช้งาน/สมาชิก | **F8** หรือเมนู *ตั้งค่า → สมาชิก* — รหัส, ชื่อ, เบอร์โทร, ส่วนลด %, หมายเหตุ (ส่วนลดถูกใช้คิดเงินอัตโนมัติ) |
| ขั้นตอนง่าย 2-3 ขั้น | ดูหัวข้อด้านบน ใช้แป้นพิมพ์ล้วนได้ |
| โปรแกรมขนาดเล็ก | ไฟล์เดียว ~64 KB ไม่ต้องติดตั้ง |
| เรียกดูรายการที่บันทึก | **F7** ประวัติ — เลือกช่วงวันที่, ค้นหาเครื่อง/ชื่อ, สรุปรายรับและเวลาใช้งาน, ส่งออก CSV เปิดด้วย Excel |
| ทำงานบน Windows | Windows Forms + .NET Framework 4 ที่มากับ Windows |
| กันเครื่อง Hang / ไฟดับ | ดูหัวข้อถัดไป |

### สีในตาราง

- ขาว = กำลังใช้ · **เหลือง** = ใกล้หมดเวลา · **แดง** = หมดเวลา (เตือนเสียงซ้ำทุก 1 นาที)
- ฟ้า = เปิดเวลา (จ่ายตอนเลิก) · เทา = หยุดชั่วคราว

## ระบบป้องกันเครื่อง Hang / ไฟดับ

- บันทึกข้อมูลลงดิสก์ **ทุกครั้งที่มีการเปลี่ยนแปลง** และ **ทุก 10 วินาที** ระหว่างจับเวลา
- เขียนแบบปลอดภัย: เขียนไฟล์ชั่วคราวให้ลงดิสก์จริงก่อน (write-through) แล้วค่อยสลับแทนไฟล์เดิม
  พร้อมเก็บไฟล์สำรอง `state.xml.bak` — ถ้าไฟดับกลางคันไฟล์ข้อมูลจะไม่เสีย
  และถ้าไฟล์หลักเสียจริง โปรแกรมจะกู้จากไฟล์สำรองให้เอง
- เปิดโปรแกรมใหม่ **รายการที่ยังไม่ได้กดชำระเงินจะกลับมาแสดงครบเหมือนเดิม**
  ถ้าโปรแกรมหยุดไปเกิน 1 นาที จะถามว่า:
  - **ใช่** — ลูกค้ายังใช้เครื่องอยู่ (เช่น เครื่องแคชเชียร์ค้างเครื่องเดียว) → นับเวลาช่วงนั้นด้วย
  - **ไม่** — ไฟดับทั้งร้าน ลูกค้าใช้ไม่ได้ → ไม่นับช่วงนั้น
- แนะนำให้ติ๊ก *ตั้งค่า → เปิดโปรแกรมอัตโนมัติเมื่อเปิด Windows* เพื่อให้ไฟมาแล้วโปรแกรมเปิดเองทันที
- ป้องกันเปิดโปรแกรมซ้อน 2 หน้าต่าง และบันทึกข้อผิดพลาดไว้ที่ `data\error.log`

## ปุ่มลัด

| ปุ่ม | ทำอะไร |
|---|---|
| Enter | เริ่มจับเวลา (ในช่องกรอก) / ชำระเงิน (ในตาราง) |
| F3 | เติมเวลา |
| F4 | แก้ไขรายการ |
| F6 | หยุดชั่วคราว / เล่นต่อ |
| F7 | ประวัติ / รายการที่บันทึก |
| F8 | สมาชิก |
| F9 | ชำระเงิน / ปิดรายการ |
| Del | ยกเลิกรายการ |
| F1 | วิธีใช้งาน |

## การคิดเงิน

- เวลาที่ได้ = จำนวนเงิน × 60 ÷ ราคาต่อชั่วโมง (หลังหักส่วนลดสมาชิก) ปัดเศษนาทีลง
- ค่าใช้เกินเวลา: ถ้าใช้เกินเวลาที่ซื้อเกินกว่า "นาทีผ่อนผัน" (ตั้งได้ ค่าเริ่มต้น 2 นาที)
  จะคิดตามนาทีที่เกิน ปัดขึ้นเป็นบาท — ตอนชำระเงินแก้ยอดนี้ได้ (เช่น จะไม่เก็บ)
- แบบ "เปิดเวลา": คิดตามเวลาที่ใช้จริง ปัดนาทีขึ้น และปัดเงินขึ้นเป็นบาท
- หน้าชำระเงินมีช่อง "รับเงินมา" คำนวณเงินทอนให้

## ไฟล์ข้อมูล (`data\`)

| ไฟล์ | เนื้อหา |
|---|---|
| `state.xml` | ตั้งค่า, รายการใช้งาน/ราคา, สมาชิก, รายการที่กำลังจับเวลา |
| `state.xml.bak` | ไฟล์สำรองของ state.xml ก่อนบันทึกครั้งล่าสุด |
| `history-YYYY-MM.txt` | ประวัติรายการที่ชำระเงิน/ยกเลิก แยกไฟล์รายเดือน (ข้อความคั่นด้วย Tab) |
| `error.log` | บันทึกข้อผิดพลาด (ถ้ามี) |

สำรองข้อมูลได้ง่าย ๆ โดยคัดลอกโฟลเดอร์ `data` ทั้งโฟลเดอร์

## โครงสร้างซอร์สโค้ด

```
netcafe-timer/
  NetTimer.exe   โปรแกรมที่คอมไพล์แล้ว พร้อมใช้
  build.bat      คอมไพล์ใหม่ด้วย csc.exe ของ Windows
  src/Core.cs    ข้อมูล, การคิดเงิน, การนับเวลา, การบันทึกไฟล์แบบกันไฟดับ
  src/App.cs     หน้าจอทั้งหมด (Windows Forms)
```
