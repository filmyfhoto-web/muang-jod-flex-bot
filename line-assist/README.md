# line-assist

ตัวตอบลูกค้าของ LINE OA ร้านนัฐภรณ์ เชียงกลาง ที่อยู่ในระบบหลังบ้านของร้านเอง (Supabase) — **แทนบอท Render (`stationery-bot/`)** เพื่อให้เหลือบอทชุดเดียว

```
ลูกค้า → LINE → line-bot (ของร้าน: เมนู, ส่งเอกสารโครงการ, การ์ดออเดอร์)
                    │  ข้อความที่ line-bot ไม่ตอบเอง ส่งต่อ ("relay") ไปที่
                    ▼
               line-assist  ← ฟังก์ชันนี้ (แทน Render)
```

ไม่แก้โค้ดของ `line-bot` เลย — เปลี่ยนแค่ "ที่อยู่ที่ line-bot ส่งต่อ" จาก Render มาเป็นฟังก์ชันนี้ (ค่า `line_webhook_prev`)

## ตอบอะไรบ้าง (เหมือนบอท Render ทุกอย่างที่ใช้อยู่)

| ลูกค้าส่งมา | ผล |
|---|---|
| เวลาเปิดร้าน / สั่งของ (ลิงก์สั่งซื้อ) / ที่ตั้งร้าน | การ์ดคำตอบ + ปุ่มหัวข้อด่วนใต้ข้อความ |
| อุปกรณ์การเรียน 2-69 → ชื่อโรงเรียน | ถาม "โรงเรียนไหน" แล้วส่งลิงก์รายการอุปกรณ์ของโรงเรียนนั้น (29 โรงเรียน) |
| ขอบคุณ / สติกเกอร์ขอบคุณ | ตอบรับ |
| สั่งงาน โฟมบอร์ด ไวนิล ปริ้นงาน… / ขอถาม มีสินค้าไหม… / คุยกับแอดมิน | การ์ด "ต้องการติดต่อใคร" (หญิง ฟิล์ม พี่ปิ่น + รูปโปรไฟล์) — ยังไม่แจ้งใคร |
| กดชื่อ "ติดต่อ หญิง" | บอทเงียบกับลูกค้าคนนั้น 20 นาที (ต่ออายุทุกข้อความ; กดปุ่มหัวข้อ/พิมพ์ "เมนู" เพื่อปลุก) และ**แจ้งเฉพาะหญิง** (การ์ดไม่มีข้อความลูกค้า) ไม่เกิน 1 ครั้ง/คน/5 ชม. |
| รูป / ไฟล์ | "ขอบคุณค่ะ ได้รับรูป/ไฟล์แล้ว" 1 ครั้ง/10 นาที + แจ้งแอดมินทั้ง 3 คน ไม่เกิน 1 ครั้ง/ลูกค้า/5 ชม. (ตั้ง `GEMINI_API_KEY` ถ้าอยากให้แยกสลิป — อ่านแค่ว่าเป็นสลิปหรือไม่ ไม่อ่านยอด) |
| ข้อความหลายอันรัว ๆ | ตอบอันเดียว (6 วินาที) |
| วันเสาร์ | ข้อความแจ้งร้านหยุด นำหน้าคำตอบแรกของวัน (ครั้งเดียวต่อคน) |
| อะไรที่บอทไม่รู้ (ชำระเงิน โปรโมชั่น ใบเสร็จ ราคาสินค้า ฯลฯ) | เงียบ ไม่แจ้งใคร — แอดมินเห็นแชทและตอบเอง |
| แอดมินพิมพ์ `ปิดบอท 2` / `เปิดบอท` / `โควตา` / `ไอดีฉัน` | ปิดบอททั้งร้านชั่วคราว / เปิด / ดูโควตา push / ดู LINE id |

**ที่ line-bot ทำเองต่อไป (ไม่เกี่ยวกับตัวนี้):** การ์ดเมนูตอนเพิ่มเพื่อน/ทักครั้งแรกหลังเงียบ 60 นาที (`menu_gap_min`), ส่งเอกสารโครงการ, การ์ดออเดอร์/ยืนยัน. ตัวนี้จึงไม่ตอบ "สวัสดี" เฉย ๆ (กันการ์ดซ้อน) — เปิดได้ด้วย `"greeting": true`

## ตั้งค่า (`app_config` → key `faq_bot`)

```json
{
  "mode": "admins",
  "admins": [
    { "name": "หญิง",   "userId": "U…" },
    { "name": "ฟิล์ม",  "userId": "U…" },
    { "name": "พี่ปิ่น", "userId": "U…" }
  ],
  "chatLinkTemplate": "https://chat.line.biz/…?openExternalBrowser=1",
  "chatLinkLabel": "เปิดแอปตอบลูกค้า",
  "assets_base": "https://<project>.supabase.co/storage/v1/object/public/line-assist"
}
```

- `mode`: `off` = ส่งต่อทุกอย่างให้บอทเดิม · `admins` = ตอบเฉพาะแชทของแอดมินในรายชื่อ ที่เหลือส่งต่อบอทเดิม (ช่วงทดสอบ) · `all` = ตอบทุกคน ไม่ต้องใช้บอทเดิม. ไม่มีค่า/ค่าผิด = `off` (ปลอดภัย)
- `admins`: ชื่อ + LINE userId (ขึ้นต้น `U` + 32 ตัว; ให้แต่ละคนพิมพ์ "ไอดีฉัน" กับ OA). **ไม่เก็บ id ไว้ใน git**
- ปรับได้เหมือนเดิม: `quietMinutes` (20) · `alertEveryHours` (5) · `pictureReplyMinutes` (10) · `burstSeconds` (6) · `notify` (`false` = ไม่ส่งการ์ดแจ้งแอดมิน) · `paused` · `greeting`
- แก้ข้อความ/คำตอบ/โรงเรียนโดยไม่ deploy: ใส่ใน `content` (คีย์ที่ยอมรับ ดู `src/config.js`) หรือแก้ `src/data.js` แล้ว deploy ใหม่

Secrets ที่ใช้ (ในตาราง `app_secrets` ที่ line-bot ใช้อยู่แล้ว ไม่ต้องตั้งซ้ำ): `line_channel_token` (มีอยู่แล้ว) · `faq_hook_key` (กุญแจร่วมระหว่าง line-bot กับฟังก์ชันนี้ อยู่ใน URL `?k=`) · `faq_forward` (ที่อยู่บอทเดิม ใช้ตอน `off`/`admins`) · `line_channel_secret` (ถ้ามี จะตรวจลายเซ็น LINE เพิ่ม)

## ขึ้นระบบจริง (ทำทีละขั้น ย้อนกลับได้ทุกขั้น)

1. **ตารางเก็บสถานะ** (เพิ่มอย่างเดียว ไม่แตะของเดิม): รัน `sql/001_st_state.sql`
2. **Deploy** ฟังก์ชัน `line-assist` — ไฟล์ใน `src/` ทั้งหมดวางแบนในโฟลเดอร์เดียว (`index.ts` เป็นตัวเริ่ม) และ **ปิด verify_jwt** (LINE/line-bot ไม่ได้ส่ง login มา; ความปลอดภัยตรวจในโค้ด: ต้องมี `?k=` ที่ตรง หรือลายเซ็น LINE ที่ถูก)
3. **ตั้งค่า** (SQL เดียว ไม่ต้องเห็นค่ากุญแจ):
   ```sql
   insert into app_secrets(key, value, updated_at) values ('faq_hook_key', replace(gen_random_uuid()::text, '-', ''), now()) on conflict (key) do nothing;
   insert into app_secrets(key, value, updated_at) select 'faq_forward', value, now() from app_secrets where key = 'line_webhook_prev' on conflict (key) do nothing;
   insert into app_config(key, value, updated_at) values ('faq_bot', '{"mode":"admins", "admins":[…], "chatLinkTemplate":"…"}'::jsonb, now()) on conflict (key) do update set value = excluded.value, updated_at = now();
   ```
4. **รูปการ์ด** (ครั้งเดียว): POST `{"action":"seed_assets","from":"https://raw.githubusercontent.com/filmyfhoto-web/muang-jod-flex-bot/<commit>/line-assist/assets"}` ไปที่ฟังก์ชัน (ใส่ `?k=`) → คัดลอกรูปเข้า Storage แบบสาธารณะ ได้ `assets_base` กลับมา ใส่ใน `faq_bot`
5. **ต่อสาย**: ชี้ line-bot มาที่ฟังก์ชันนี้
   ```sql
   update app_secrets set value = 'https://<project>.supabase.co/functions/v1/line-assist?k=' || (select value from app_secrets where key = 'faq_hook_key'), updated_at = now() where key = 'line_webhook_prev';
   ```
   ตอนนี้ลูกค้าทั่วไปยังไปทาง Render เหมือนเดิม (ส่งต่อผ่านฟังก์ชันนี้, `mode = admins`)
6. **ทดสอบกับ LINE แอดมิน 3 คน** (ดูรายการด้านล่าง)
7. **เปิดทุกคน**: `faq_bot.mode = "all"` และ `line_bot.admin_pick = false` (ปิดการ์ดเลือกแอดมินของ line-bot — ไม่งั้นข้อความที่มีคำว่า "แอดมิน" จะไปได้การ์ดของ line-bot แทน เหลือแบบเดียว)
8. ใช้ 1–2 วัน ไม่มีปัญหา → ลบบริการ Render และโฟลเดอร์ `stationery-bot/`

### ทดสอบกับแอดมิน (ขั้น 6)
- ส่ง "เวลาเปิดร้าน", "ที่ตั้งร้าน", "สั่งของ", "อุปกรณ์การเรียน 2-69" แล้วพิมพ์ชื่อโรงเรียน → ได้การ์ด + ปุ่มด่วน
- ส่ง "สั่งงานไวนิล" → ได้การ์ดเลือกคน (มีรูป) แต่ยังไม่มีใครถูกแจ้ง
- กด "ติดต่อ …" → ไม่มีข้อความตอบ, **เฉพาะคนนั้น**ได้การ์ดแจ้งเตือน (มีปุ่มเปิดแอปตอบลูกค้า), พิมพ์อะไรต่อบอทเงียบ, กดปุ่มหัวข้อ → บอทกลับมา
- ส่งรูป/ไฟล์ → ได้ "ขอบคุณค่ะ ได้รับรูป/ไฟล์แล้ว" และแอดมินทั้ง 3 ได้รับแจ้ง 1 ครั้ง ส่งซ้ำไม่ซ้ำ
- พิมพ์ข้อความที่บอทไม่รู้ → เงียบ

## ย้อนกลับ (เร็วที่สุดก่อน)
- `update app_config set value = jsonb_set(value, '{mode}', '"off"') where key = 'faq_bot';` → ส่งต่อทุกอย่างให้ Render ทันที
- หรือคืนที่อยู่เดิม: `update app_secrets set value = (select value from app_secrets where key = 'faq_forward') where key = 'line_webhook_prev';` → line-bot ส่งตรงไป Render เหมือนเดิม
- (ถ้าเปิด `admin_pick=false` ไปแล้ว ให้ตั้ง `true` คืน)

## ทดสอบ
```bash
cd line-assist && node --test        # 104 ข้อ (Node ≥ 20; รันใน Deno 2 ก็ผ่าน: deno test --allow-all)
```
ไม่มี dependency และไม่ต่อเครือข่ายจริง (LINE/ฐานข้อมูลจำลองในเทสต์)

## ข้อควรรู้
- การ์ดแจ้งเตือนและตอบด้วย reply token เป็นข้อความฟรี; การ์ดแจ้งแอดมินเป็น push นับโควตารายเดือน (พิมพ์ "โควตา" ดูได้) เหมือนบอท Render
- ข้อความที่ line-bot ตอบเอง (เมนูหลังเงียบ 60 นาที ฯลฯ) ไม่มีประกาศวันเสาร์ — ประกาศจะมากับคำตอบแรกของตัวนี้
- รูป avatar ของบอท (`sender.iconUrl`) ใช้เฉพาะข้อความจากตัวนี้ ข้อความของ line-bot ใช้รูปโปรไฟล์ OA ตามปกติ
- ถ้า Storage/`assets_base` ยังไม่ตั้ง การ์ดจะไม่มีรูปมาสคอต (ข้อความยังครบ)
